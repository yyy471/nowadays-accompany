## 2. 代码修改

| 文件 | 修改 |
| --- | --- |
| `desktop/renderer/src/components/WorldbookEditor.tsx` | 新增生命周期 effect 与实例序号；`isCurrent(instance)` 校验挂载、实例和锁；保存/试算/删除确认/关闭在 await 后复核；copy 初始为未保存新资源 |
| `desktop/renderer/src/components/WorldbookSettings.tsx` | 来源意图序号与列表/详情独立序号；隐藏、锁定、禁用、身份变化作废旧意图；列表分页、合并去重、按页加载；加载更多与重试 |
| `desktop/renderer/src/components/WorldbookLibrary.tsx` | 复制新书使用安全副本 id，并检查已加载 id 冲突 |
| `desktop/renderer/src/lib/worldbook-editor.ts` | 通用 `duplicateSegmentId`；条目与书籍副本共用后缀预留算法；`copyBookId` |

关键语义：

- 卸载后 `mounted=false` 且实例序号递增；旧请求即使晚返回也不调用 `onSaved`/`onRefresh`，不更新状态。旧回调在发请求前即被挂载检查拒绝。
- 来源选择以“最后一次用户意图”为准：慢列表、乱序列表、隐藏、锁定、账号切换都不会把 source 改回旧选择；列表结果仍可缓存。
- 分页只加载摘要，不自动拉取全部正文；失败保留已加载项，重试按当前进度继续。
- 副本 id 先为 `-copy` 和后缀冲突预留长度；64 字符源 id 的副本仍为 64 字符且不等于原 id。copy 不修改任何内容即可保存。
