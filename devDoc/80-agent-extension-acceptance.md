# Agent、统一工具与扩展作用域验收标准

日期：2026-10-26。状态：待实施、待执行。方案见[79 执行方案与任务拆分](79-agent-extension-execution-plan.md)。

范围仅阶段回顾第2、3、4项。单一插件标准，不验收旧插件兼容模式；记忆管理页面后置。下列“预期”是开发完成要求，不代表当前已满足。

## 1. 验收原则与环境

检查完整链路：用户可配置→后端持久化→有效策略→运行时执行→实际回复/结果→错误可诊断。接口存在、描述注册成功、页面有按钮分别都不能证明功能闭合。

准备账号A/B、相同peerId的群/私聊、两个不同角色contextEpoch、公用和私有同id插件、仅A拥有的插件、两个互不依赖插件、声明缺handler插件、故障/超时插件、多个Skill来源、普通模型与支持工具模型、FakeChannel及可门控Provider。数据使用隔离临时目录，覆盖写入失败、慢结果、撤权和重启。无需真实浏览器、QQ或付费服务。

P0：越权、串账号/作用域、失效结果写回、重复外部动作、未授权模型或工具调用、敏感数据泄漏。P1：主链不闭合、无限循环/等待、配置丢失、成本/限额失效、协议错误。P2：非阻断体验或诊断缺陷。P0/P1未关闭不能放行；任何测试失败都应有诊断，不能重跑到绿后删掉此前失败记录。

## 2. 契约和单一编排（C/A）

| ID | 等级 | 场景 | 预期 |
| --- | --- | --- | --- |
| C01 | P1 | 导入与目录读取同一插件manifest | 同一严格schema；声明、版本、输入schema和handler契约一致 |
| C02 | P0 | 工具未声明、缺handler、重复模型名/完整身份冲突 | 拒绝注册或明确不可用，不向模型提供无执行器工具 |
| C03 | P1 | 开发数据含replyMode/旧enabledTools等 | 一次性整理有明确改动范围，模型/凭据/角色/原授权不丢；运行时无双授权和兼容分支 |
| A01 | P1 | 为已有账号安装启用插件 | Agent仍是编排者，角色/世界书/记忆仍进入实际请求，不切换为插件独占回复 |
| A02 | P0 | 无角色绑定、账号暂停、解绑、退出 | 不调用自动模型/插件工具，不通过钩子绕过 |
| A03 | P1 | beforeContext返回数据、afterTurn收到结果 | 来源明确，数据进入实际上下文，通知反映真实发送状态；只产生一次最终文本回复 |
| A04 | P1 | 钩子失败/超时/错误返回 | 当前插件本轮失效，Agent可继续；不阻塞其他插件和下一会话 |
| A05 | P0 | 插件返回旧reply/sends或尝试改变角色/权限 | 不按旧协议执行，不直接发QQ，不提升权限 |
| A06 | P1 | 相关扩展变化与无关账号变化 | 前者旧任务失效，后者当前轮继续；角色历史和记忆epoch不被扩展策略改写 |

## 3. 工具执行与模型协议（T）

| ID | 等级 | 场景 | 预期 |
| --- | --- | --- | --- |
| T01 | P0 | 未授权工具、未安装插件、无capability工具 | 都经完整授权；capability为空不能默认放行；Provider前/动作前调用数为0 |
| T02 | P0 | 错误参数、未知工具、重复callId、超限或不支持的schema | 注册或整批预检明确拒绝；该批副作用0，不动态import或执行字符串 |
| T03 | P1 | 同响应两条工具调用 | 按原顺序处理且各有匹配结果，不能只执行第一条 |
| T04 | P1 | 模型调用→工具返回→模型续答 | 实际assistant.tool_calls与tool_call_id正确配对，续答实际使用返回数据；不使用普通user文本冒充协议 |
| T05 | P0 | 模型返回文本和工具调用；结果夹带“系统命令” | 中间文本不提前发；数据保持tool来源，不改系统权限或角色 |
| T06 | P1 | 工具异常、业务错误、超长结果、无法加入上下文 | 返回有限安全状态，不泄漏栈/密钥，不无界扩容，不假称成功 |
| T07 | P1 | 循环请求工具、反复修复参数、缺callId | 调用ID确定，遵守3工具回合/4工具调用/4模型调用上限；拒绝也计预算，无无限续答 |
| T08 | P0 | 排队中撤权、插件换版、角色/记忆guard变化 | 未开始动作0次；在途晚结果不进入新轮或QQ交付 |
| T09 | P1 | 模型不支持工具 | 正常文本回复，描述不伪装成工具协议，工具调用0 |
| T10 | P1 | 批次预检通过后第二项执行失败 | 已发生动作不伪称回滚；每项结果真实，不能把失败项报告成功 |

工具集成证据必须捕获真实ProviderAdapter收到的请求体，检查assistant/tool消息结构和调用ID；只对内部ToolExecutor做单测不足以验收T04。

## 4. 调用账本、预算与生命周期（L/W）

| ID | 等级 | 场景 | 预期 |
| --- | --- | --- | --- |
| L01 | P0 | 同invocationKey重复通知/回调/重启后恢复 | 副作用不重复；成功返回已有有限结果，进行中/unknown不重跑 |
| L02 | P0 | 同key不同参数、跨账号伪造media/job引用 | 冲突或拒绝，不执行第二次，不读其他账号结果 |
| L03 | P0 | started意图落盘失败 | 动作0次；不能先动作后补账本 |
| L04 | P0 | 动作开始后、成功记录前崩溃 | 恢复unknown/interrupted，无自动付费重放，不承诺外部exactly-once |
| L05 | P1 | 账本满额、达到字节上限、未知动作长期存在 | 有界拒绝，不清掉未知记录后重跑；保留窗口明确 |
| L06 | P1 | 超过全局4/账号2并发或32排队 | 限额准确、队列有界、普通不同会话可继续；拒绝原因明确 |
| L07 | P0 | 退出、Provider/Worker不响应abort | 停止新准入，有限等待，晚结果不能发送或写新状态；不假称远端动作撤销 |
| W01 | P0 | 同id公用/私有插件及账号A/B | handler、state、回执、授权均不串；来源完整且可见 |
| W02 | P0 | 群/私聊同peer、角色切换 | 默认插件会话状态按kind/peer/contextEpoch隔离；账号共享状态需显式声明启用 |
| W03 | P1 | 插件P死循环/超时，插件Q正常 | 终止P代际，丢弃P晚状态，Q与正常Agent继续；无无限关机 |
| W04 | P0 | Worker回复旧requestId/代际/跨账号scope | 拒绝，无状态或媒体写入 |
| W05 | P1 | 工具调用宿主能力端口、媒体回调排回会话 | 无插件RPC与当前会话队列互等；不等待自己占用队列才能完成的工作 |
| W06 | P1 | 同插件并发会话写状态、版本stateVersion不兼容 | 写入串行且无旧快照覆盖；不兼容明确拒绝/迁移，不静默丢状态 |

## 7. 必需端到端证据（E）

必须提供以下真实装配链路，不能仅拼接独立单测结果：

1. **E01 / P1 插件闭环**：本地示例插件导入→账号启用并限定群/私聊→声明/handler就绪→实际QQ假通道消息→正常Agent请求出现该工具→模型调用→Worker执行→tool结果进入下一次模型请求→最终回复经原通道发送并持久化。记录工具完整身份、批次ID、调用数、state变化、最终发送数，不记录真实聊天。
2. **E02 / P0 隔离**：相同peerId的账号A/B、群/私聊四个scope，只有指定scope能看见和执行工具；私有同id插件不会覆盖公用handler。
3. **E03 / P0 在途撤权**：门控暂停模型响应、工具排队、动作执行及结果返回各阶段，分别撤权/换版/解绑；未开始动作0次，旧结果不发送、不写新状态。
4. **E04 / P0 恢复**：意图记录失败、动作后崩溃、重复回包和重启；实际动作计数与账本状态相符，无自动重放。
5. **E05 / P1 Skill闭环**：公用创建→复制私有→指定群启用→实际上下文包含正确说明→关闭所需工具后Skill不再注入并显示原因。
6. **E06 / P1 媒体闭环**：统一工具触发生图或语音→原任务存储→生成→原会话受控交付；累计提交、生成和发送次数一致。

示例插件采用无网络确定性数据查询和可控本地状态动作，足以验证统一工具能力；不能用它宣称真实网页/视频/空间功能完成。

## 8. 回归和交付门槛（R）

- R01：原文字对话、逐会话角色、世界书、事实记忆注入、MEM03纯文本提取、图片/视频/生成媒体、队列背压、注入监听、凭据和退出链路不退化。
- R02：有工具/插件补充数据的轮次不触发自动事实提取，内部tool消息不被保存成用户输入或发送到QQ。
- R03：代码搜索确认不存在第二个生图/语音执行分支、旧onMessage回复协议、replyModeFor、空capability默认授权、前端独立作用域计算等废弃路径；协议消费者、样例、DTO及导出一致。
- R04：最终运行`npm test`、`npm run typecheck`、`npm run desktop:build`、`git diff --check`，记录实际结果；新增失败/skip不以环境或历史原因直接豁免，保留失败现场。
- R05：后端自动验证与前端实际交互证据分别提供。没有原生窗口/真实服务条件时明确限定范围，不将HTTP通过描述为原生界面或真实QQ验收。

执行报告按EXT-A～H列代码、验收ID、持久化/运行状态、故障与未完成项；每个副作用场景至少记录实际handler/Provider调用数、回执状态、消息发送数。测试源码入Git，临时产物留在忽略目录。未经请求不提交、打包、发布或替换EXE。

放行措辞：A/B单包仅为底座完成；C/D仅证明插件工具可运行；E/F/G接通且上述关键项通过后才能声明“Agent主体+统一工具+扩展作用域及Skill管理闭环完成”。记忆管理页面、具体浏览工具及操作系统沙箱不在该声明内。
