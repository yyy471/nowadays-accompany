# 主页与全局公共动效接入验收标准

日期：2026-10-28。配套方案：[125 接入计划](125-home-and-global-motion-integration-plan.md)。状态：实现方已按本表完成自验，结果见[127 执行记录](127-home-and-global-motion-integration-execution.md)；[128 独立复核](128-home-and-global-motion-independent-review.md)的R1～R3已由[129 修复记录](129-home-and-global-motion-review-fixes.md)处理，独立复验待做。本文件仍是验收口径，不代替复核记录。

## 1. 验收口径

**全局组件统一接入，页面设计只改主页。** 全局壳、按钮、浮层等可影响现有页面的公共表现；其他页面保留既有布局、信息、业务流程和主题作用域。检查旧页面用于验证公共契约，不代表其页面设计已验收。

每个HM工作包由实现方自验与独立复核分别留记录。静态token、HTML样板、mock组件测试、浏览器生产构建和原生Electron分别记录；不能互相冒充。真实QQ/付费模型及完整发行包仍不由本包验收覆盖。

## 2. 必须通过的检查项

| 编号 | 检查 | 通过条件 |
| --- | --- | --- |
| G01 | 唯一公共实现 | 无主页/旧页两套Dock、Modal或按钮动效；全局与主页消费同一策略及token；未引入无必要的新引擎 |
| G02 | 作用域隔离 | 新动作可全局使用；未设计页不被统一xiacheng DOM包装改变尺寸/配色；不重排其业务内容，不改后端 |
| G03 | 减少动效 | system遵循系统，reduced直接终态，full可覆盖系统reduce；JS/CSS结论一致，forced-colors禁装饰但保留选中/焦点/文字 |
| G04 | 活动中改偏好 | 按压、书签移动、菜单/弹窗进退、阅读和天气过渡期间切换偏好，立即收束到正确可操作状态，无残留transform/定时器 |
| G05 | 生命周期 | 反复开关/切页/缩放、失焦、隐藏、主题变化、卸载后无孤立监听器/rAF/旧回调；实例状态不串；无模块级新增可变单例 |
| G06 | 参数 | token check通过；ms/s均可解析；生产压缩后时长正确；关键运动使用transform/opacity，不做整窗追光/空闲循环 |
| B01 | 入口书签 | hover与focus-visible有端片反馈，按压收回；1px按压、3px探出/8px尾部上限/2px箭头来自token；布局和命中框不跳 |
| B02 | 输入与状态 | 鼠标、Enter、Space各激活一次；busy阻止重复且焦点/按钮宽度稳定；禁用无误触，危险按钮不变为入口语义 |
| B03 | 真实结果反馈 | 真实成功才勾画/落款；失败保留内容，未知不宣告成功；重渲染、切主题、旧请求晚到不重播/不归到新账号或对象 |
| B04 | 能力与消费者分开 | 没有真实保存结果输入的旧调用标明待接点；不伪造主页保存流程；导航不显示“已收好” |
| D01 | 双主题Dock | 按120的纸签/布面、图上文下、单个当前索引、更多分隔落地；普通文字4.5:1，必要边界/图标/焦点3:1，按最终叠色验证 |
| D02 | 尺寸 | 常规68px、紧凑64px、短窄58px，命中≥44px；文字及命中框不随hover/press移动；footer与内容预留不被压缩为Dock实际高度 |
| D03 | 动作幅度 | 独立hover/press/follow层；跟随≤±1px、hover -2px、按压+1px/0.96，文字不动；选择移动220ms、回弹≤1.5px |
| D04 | 真实路由 | 准入前不改selected；取消留原页，成功才提交目标；当前页重复点击不重播；历史前进/返回、外部合法导航同步选中 |
| D05 | 快速反向 | 连续点不同项取最新合法路由，从当前绘制位置衔接；无历史动画队列，旧结束回调不清理新动画 |
| D06 | 更多 | 打开菜单不切页；仍是真实DropdownMenu，非直接入口才选更多；菜单选项走真实导航/草稿准入，没有HTML占位目的地 |
| D07 | 指针与键盘 | 松开、移出、pointercancel、窗口失焦/隐藏、resize均释放按压；触摸不留hover；Enter/Space原生语义，Tab焦点不被装饰吞掉 |
| S01 | 菜单来源与定位 | 160ms内动作；边缘/缩放后不出视口，长菜单内部滚动；方向键/Home/End/搜索/Tab/Esc及返回焦点保留 |
| S02 | 模态生命周期 | 打开立即隔离；退出结束前隔离持续；嵌套只顶层响应Esc，确认取消初始焦点与返回焦点正确；背景滚动锁恢复准确 |
| S03 | 中断和来源丢失 | 快速开关从当前状态过渡；trigger消失有安全退化；外部open变化、closeDisabled、卸载/安全退出不重复onClose、不留透明挡板 |
| S04 | Disclosure/Switch | 折叠保留编辑器、草稿、选区，关闭内容不可Tab/操作，内部焦点先回触发器；Switch真实值及aria同步，不靠动画延迟状态 |
| H01 | 阅读顺序 | 主页标题→资料/空态→入口等少量分组，间隔24ms、累计≤72ms，总完成≤280ms，位移4px；小窗口仍可立即点击入口 |
| H02 | 不误重播 | 进入/返回主页一次入场；切主题仅天气过渡；轮询/SSE/账号刷新/重试不重建页面或重播整页，没有多余业务请求 |
| H03 | 一屏与错误 | 双主题无主页纵向滚动；长昵称/QQ/长签名、错误/空态/加载仍可读，原因与重试入口不被overflow隐藏，按钮不被Dock/立绘覆盖 |
| H04 | 素材与跟随 | 不换已采用立绘；冷加载和失败有稳定回退；跟随遵循有效偏好，失焦/隐藏清零；不新增候选环境光、纹理或模拟事件 |
| R01 | 草稿准入 | 在现有角色或模型页留下真实未保存草稿，经Dock/更多/返回主页：取消完整保留，确认按既有协议处理，动画不抢跑 |
| R02 | 退出协议 | 菜单/弹窗/动画活跃期间触发安全退出，锁定/inert正确；取消退出恢复交互，批准退出不被动画拖延或重新激活 |
| R03 | 老页面不重设计 | 对工作台、角色、模型、资源、插件、诊断、设置执行代表性回归；除公共控件/壳动作外，布局、滚动、业务控件与草稿不变 |
| R04 | 无新增业务副作用 | 动画只改外观，不写账号/模型配置、不启动QQ/SnowLuma、不自动注入、不调用模型、不重复请求或提交 |

跨页全局入场只提供公共的轻量进退/生命周期，不给未设计页擅自加入逐段阅读编排。抽屉无实际消费者则后置，验收表写“本轮不接入”，不为补齐效果发明页面。

## 3. 环境与证据矩阵

- 主题：daylight、nightwave；状态：default/hover/focus/pressed/disabled/busy/error/success（仅适用控件）。
- 视口：1440×900、1280×800、1024×720；回退600/599、360/359宽及短窄≤680高，检查120断点两侧。不是把回退尺寸宣称为当前Electron最小窗口支持。
- Electron：真实窗口100%与125%缩放，包含双主题Dock、菜单/设置、草稿取消和退出组合；报告CSS视口与原生尺寸/缩放，不仅截图浏览器模拟尺寸。
- 输入：鼠标、键盘、触摸指针；触摸可在支持的自动化中验证pointerType与残留，未有真实触屏证据时标明。
- 可访问性：减少动效、full覆盖、forced-colors、可读标签、立即焦点；静态截图不能证明连续中断/焦点正确，需交互日志或可复现脚本。
- 资源：生产dist而非仅Vite开发版，冷加载、缺图、缓存资料+失败，以及真实更多菜单/弹窗退出；不复制HTML假请求替代正式组件。

## 4. 自动化与实际执行

按变更补充有意义的契约/行为测试：偏好优先级、Dock准入/取消/重复/中断、Modal退出隔离、折叠保留节点、结果代际和主页重播边界。旧回归源码保留，不为变绿删掉草稿、焦点或时限断言。

最终门控：

```text
npm run ui:tokens:check
npm run typecheck
npm test
npm run desktop:build
git diff --check
```

再运行按本包补充的生产界面/原生验证脚本。脚本命令、运行窗口、真实结果和失败修复要写执行记录；不预先填写通过数字。只有规范/HTML检查不能关闭正式接入项。

## 5. 收口与未完成项

每个HM包提供：实现文件清单、公共API变化及兼容说明、真实消费者清单、token登记/生成证据、原始失败与修复、自动化结果、双主题界面与交互证据，以及独立复核文档。

未达到条件的项目单独列出原因，不能随其他包一起标完成。通过后仍后置：其他页面视觉设计、未采用的主页视觉候选、无消费者的抽屉/保存结果调用点、真实QQ/模型联调和完整发行包验收。
