# 主页账号展示与工作台：设计调整

日期：2026-10-22。

用户明确要求：主页展示 QQ 账号形象、名称、QQ 号和个性签名，不展示聊天记录，不提供实际运行操作；底部为 macOS Dock 风格账号选择；全局为温暖基调，避免纯黑底。工作台承接所有实际管理操作。

## 1. 页面职责

| 页面 | 职责 |
| --- | --- |
| 主页 | 当前账号图片、QQ 名称、QQ 号、个性签名与展示切换；允许留白 |
| 工作台 | 沿用前版清晰的实例管理布局，包含探测、注入、监听、暂停、模型配置、插件与任务管理 |
| 资源 | 公用定义、个人资源管理；账号图片编辑入口可在账号设置中提供 |

主页不得出现消息输入框、发送、注入、暂停、恢复、停止、卸载等运行操作。切换展示账号不切换实际 QQ 登录状态，不启动或停止任何实例。

工作台可以沿用“左导航 + 中间列表 + 右详情”的操作结构，但换为同一套暖灰、燕麦、米白与琥珀设计 Token，不保留旧版纯黑压底。

## 2. 主页布局

- 顶部轻量导航：主页、工作台、资源。
- 左侧为当前账号头像或自定义展示图片，柔和融入背景；图片不是固定出厂角色立绘。
- 右侧仅展示 QQ 身份及其个性签名，保留充分留白，不放模型/插件配置。
- 底部悬浮 Dock 为唯一主要账号切换入口，不使用整条控制台式轨道。
- 颜色参考：奶油白 #F2EDE3、燕麦色 #E8E0D3、暖褐灰 #62584D、深棕文字 #433B34、低饱和琥珀 #C08F4A；需在真实组件验证对比度。
- 无签名时显示“暂无个性签名”或安静的空状态，不用模型自动编造签名。
- 名称、QQ 号和签名属于账号信息，角色卡内的名字/设定不能静默覆盖 QQ 资料。

## 3. Dock 交互契约

- 未选中头像较小，当前展示账号保持稍大并有持久选中点/短线。
- 悬停头像顺滑放大，相邻头像按距离轻微放大、让位，离开后回到选中/未选中各自基准尺寸。
- 悬停不切换主页，仅显示昵称提示；点击、触屏点按或键盘激活才切换。
- 键盘焦点有独立可见样式，Tab 聚焦不切换，Enter/Space 激活后切换。
- 主图、名称、QQ 号、签名按同一账号原子切换，不出现旧图片配新 QQ 号。快速切换取消旧加载和未完成过渡。
- 图片切换约 220–320ms 交叉淡入；Dock 使用可中断弹性过渡，避免连续鼠标运动导致重复启动整段动画。
- 触屏不依赖悬停；减少动效时保留选中尺寸差异，移除弹跳与连续放大。
- 账号多时提供有边界的横向浏览或账号选择器，不把所有图标压缩到难以点击。活动账号/当前展示账号始终可识别。
- 动效只影响展示，不调用注入、模型或发消息 API；窗口隐藏时停止装饰动画。

## 4. 图片与资料来源

推荐账号展示模型独立于角色卡：accountId、nickname、signature、avatarMediaId、showcaseMediaId、imageFit、focalPoint、profileUpdatedAt。

图片优先级：账号本地自定义展示图片 → 已取得的当前 QQ 头像 → 中性默认头像。用户可在工作台账号设置上传/更换/重置为 QQ 头像，主页本身保持纯展示。

- 展示图片作为账号私有媒体保存，不能仅保存用户原文件路径或依赖上传后原文件继续存在。
- 上传验证图片类型、大小与解码有效性；账号目录和媒体访问鉴权继续隔离；导出/清理有明确行为。
- 远端头像 URL 可能失效，应有受控获取与本地缓存；不得将任意路径作为可公开访问资源。
- QQ 名称/签名的实际读取能力依 SnowLuma/OneBot 已验证接口决定；不假设所有版本都提供，不为取资料绕过登录/账号校验。
- 账号未绑定时只用占位资料；资料读取失败可显示该账号缓存与更新时间，不串用其他账号资料。离线也可展示已缓存信息，不假装在线。

另提供轻量 Dock 交互示意，使用文字头像占位，验证邻近放大、选中、点击切换、键盘焦点；不代表完整主页已开发。

浏览器检查：点击晚晴后名称/QQ 号/签名同时改变；Tab 移到晴川时焦点与放大改变，但当前展示仍为晚晴；相邻图标之间保持间距。发现 Dock 提示可能靠近正文后已增加展示区留白。

## 6. 实施验收

1. 主页无对话与运行操作；工作台承担实际管理。
2. 当前展示大小与普通头像有稳定差异；悬停放大不误切换账号。
3. 头像、名称、QQ 号、签名同源切换，快速连续选择不串资料。
4. 鼠标、键盘、触屏均可选择；减少动效模式可用。
5. 5 个账号和较多账号时无重叠/不可达项；Dock 不遮挡签名。
6. 仅有默认 QQ 头像、长昵称、空签名、多行签名和宽/竖上传图都可用。
7. 自定义图片保存后重启仍有效，重置恢复该账号头像，不影响其他账号。
8. 账号离线时可显示缓存资料，但不误报连接状态。
9. 主页和工作台共享温暖色系，工作台仍保留明确操作层级；实际控件无纯黑大面积背景。

本次只调整设计说明与示例，没有修改业务运行代码。
