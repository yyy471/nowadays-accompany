# 控件风格复核（0.2.3）

日期：2026-10-23。设计依据：燕麦白、暖灰、琥珀强调色，轻边框、柔和阴影、留白与克制动效。

## 结论与调整

共享按钮、搜索框、输入框、下拉框、设置弹窗和确认弹窗已基本匹配当前设计语言。本轮调整残留的不一致，未改动业务流程。

| 控件/元素 | 发现 | 处理 |
| --- | --- | --- |
| 复选框、单选框 | 保留系统默认硬边外观 | 组件库统一暖白底、琥珀选中、柔和圆角；包含禁用、焦点、不确定状态；高对比模式回退系统绘制 |
| 状态标签、状态点、错误提示 | 旧版荧光绿、亮粉、浅蓝及发光残留 | 共享RGB语义变量统一为低饱和绿、赭黄、砖红、灰蓝；光晕改为淡色外环 |
| 分隔线、行悬停、滚动条、辅助文字 | 部分仍为冷灰 | 统一使用暖灰变量和现有文字色 |
| 成功提示 | 琥珀底与绿色边框混用 | 同一绿色语义的淡底与边框；警告保留暖琥珀色 |
| 链接、文字操作 | 小字号琥珀文字偏浅 | 增加深琥珀文字色，与按钮填充和焦点强调色分开 |
| 资料页头像 | 主页大头像规则影响编辑表单，1280px窗口下约390px | 大尺寸限定在主页，资料页恢复最高172px；主页展示尺寸保留 |

组件库入口仍为 `desktop/renderer/src/ui.tsx`，交互控件外观位于 `ui/theme.css`；全局色彩变量及布局位于 `styles.css`。页面可排列组件，不另造同类控件外观。
