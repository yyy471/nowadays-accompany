## 2. R1 / P1：编辑器mounted标志没有卸载清理

位置：desktop/renderer/src/components/WorldbookEditor.tsx:46、61–62、137–162。

组件声明mounted=useRef(true)，但没有生命周期effect在卸载时置false。isCurrent因此只依赖一个永远为true的mounted与最近locked值。草稿注册的清理只注销registry，不会更新该ref。

已复现：编辑名称→保留保存回调→执行组件卸载清理→调用旧保存回调；仍发送POST /worldbooks/revisions，且响应后继续调用onSaved/onRefresh。这与“卸载后旧回调不再执行”的验收要求不符，也可能让迟到响应影响已经离开的资源视图。

修复：补生命周期清理及必要的实例/请求身份，使卸载后的编辑、保存、试算、确认后回调和响应均拒绝。重挂载应使用自己的新状态，不能复活旧实例。UI禁用和草稿registry不是该保护的替代。

新增正式回归：卸载前捕获的保存/试算回调不发请求；已发请求晚返回不触发父回调；删除确认等待期间卸载后不修改草稿。测试应调用真实cleanup，不能只测试locked。

对应54号W06，47号U06/U07。

## 3. R2 / P1：异步选书覆盖用户后续选择

位置：desktop/renderer/src/components/WorldbookSettings.tsx:87–99、139–156。

chooseKind('artifact')等待loadVersions后只检查isCurrent（挂载和账号/会话身份），没有检查“最后一次来源选择”的序号，也没有在该continuation中重验visible/locked/disabled。

已复现：初始内置书→选择独立书触发慢列表请求→请求结束前再选择内置书→返回列表；最终source仍被旧请求改成artifact。用户最后的选择被覆盖，之后保存可能选用用户已放弃的来源。类似的迟到选择也可在隐藏/退出锁后继续改变草稿。

修复：为来源选择使用独立意图序号，切来源/账号/隐藏/卸载时作废旧意图；await后既核验身份、最新意图，又核验当前可操作状态。列表结果可以缓存，但旧选择不应据此自动改写source。详情请求序号不能替代来源选择序号。

新增正式回归：独立→内置慢响应、两次相反来源选择乱序、加载期间隐藏/锁定/账号切换；最后用户选择保持，旧continuation不能改草稿或发起无效详情请求。

对应54号W06/W07/W08，47号U06/U07/U08。

## 4. R3 / P2：会话选择器忽略列表分页

位置：desktop/renderer/src/components/WorldbookSettings.tsx:87–99、210–217、238–265。

只请求/worldbooks?limit=100并保存items，完全忽略nextOffset。世界书及版本选择仅由该数组生成，页面无加载更多/按书查询入口。资源库WorldbookLibrary虽能分页，但不会把其加载结果传给这个独立选择器。

因此，超过100个资源版本时，未绑定的后续书/版本无法从会话界面选中；“当前引用”占位只保证旧引用不消失，不能选择新的后续资源。刷新仍是同一页，不能恢复。

修复：提供有界分页/加载更多，或分离“选书摘要”和“按id加载版本”的请求，确保所有合法书/版本可达；不采用无上限自动拉取所有正文。合并去重、失败保留旧项、旧响应保护应与列表共用。

正式回归至少准备101个版本，覆盖同书第101版与第二本书落在后页；实际选择后提交完整固定ref，并确认列表仍不包含正文。

该问题来自生产请求与选择器代码核验；本轮没有把分页后资源的实际浏览器选择声称为已执行。对应W01/W07。

## 5. R4 / P2：复制为新书的初始保存与长ID不正确

位置：WorldbookEditor.tsx:34、56；WorldbookLibrary.tsx:105。

其一，isNew仅对create为true，copy的baseline又直接取副本seed；刚打开副本时dirty=false，保存被禁用。已通过组件探针复现：用户必须额外修改某个字段才能保存本应已经是新身份的副本。

其二，副本ID使用`${value.id}-copy`.slice(0,64)。原ID已有64字符时后缀全部截掉，副本ID与原书完全相同。服务端不可变版本会阻止覆盖，但用户得到的不是新书身份；可能遇到409或把后续版本加到原书。

修复：copy与create都应视作尚未保存的新资源；副本ID先为后缀预留长度，并检查已知冲突，最终冲突仍由服务端处理。已有duplicateEntryId的“先截断主体、再加后缀”原则可复用为通用安全副本ID工具，不再写第二个不一致算法。

正式回归：不修改内容的副本可直接保存且只调用一次；63/64字符ID、重复副本、目标已存在409保留草稿；原书及原会话引用不变。

副本无法直接保存已运行探针；长ID为确定性表达式核验。对应54号W02/W04。
