## 4. 已知限制与风险

1. **群聊作用域的直接调用链**：POL-01 只验证了解析与账号级禁用；工具分发/Hook/直接调用的群聊端到端仍需补测。
2. **并发写同一插件状态**（CON-06）没有专门测试；当前依赖 worker 单会话串行与状态整体写回，存在丢更新风险需要后续用 CAS/事务补强。
3. **禁用插件后的在途回调**（POL-04）没有专门测试；插件宿主被禁用/切换时，已经在途的插件回调是否继续推进状态尚无独立证据。
4. **远端任务恢复**：重启后非终态任务统一标 `interrupted`，没有持久化远端任务 ID 并恢复查询的实现证据，不能称为已恢复查询。
5. **Prompt 注入**：观察数据已隔离为数据，但模型是否遵守授权只依赖 prompt 和路由层；没有真实对抗样本测试。
6. **媒体预览**：浏览器以 blob URL + Bearer 请求加载，CSP 已允许 `blob:`；大媒体列表会一次性下载所有预览，后续应改为按需加载。
7. **真实适配器**：OpenAI-compatible 与 video polling 只对本地 HTTP 假服务验证过协议与错误分类，没有验证具体厂商的响应差异。
8. **桌面端**：托盘、关闭到托盘、单实例锁沿用上一版实现；本次冒烟验证了启动/窗口/退出，未做交互式托盘点击自动化。
