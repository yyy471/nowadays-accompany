# 前端设计实施验收清单

日期：2026-10-22。配合 13 方案使用；所有项目为待验收，不因设计图存在而标记通过。

本表已按15修订：9个主页面，五类模型能力按账号配置；无会话页面或任务/媒体历史展示；每个群聊、私聊独立绑定角色卡且无默认卡。

| 编号 | 检查 | 通过条件 |
| --- | --- | --- |
| UI-01 | 顶层职责 | 主页纯展示、工作台操作、资源管理定义；主页无注入/发送/暂停按钮 |
| UI-02 | 统一风格 | 9个主页面共用语义Token；无会话/任务媒体/独立模型服务导航，账号策略更名模型配置 |
| UI-03 | 字体 | 正文和表单无衬线；展示字体限制使用，12px 辅助/14px 正文实际可读 |
| UI-04 | 资料来源 | QQ 名称/号/签名与角色卡分开；无签名不自动编造 |
| UI-05 | 默认图 | 自定义图/QQ 头像/占位优先级正确；普通小头像也能完整排版 |
| UI-06 | 上传恢复 | 图片验证与账号隔离；复制后持久化，重启可用，重置只影响该账号 |
| UI-07 | Dock 选择 | 选中持久稍大，悬停只放大，点击/Enter/Space 才更新展示 |
| UI-08 | Dock 邻近 | 放大与位移同源，无重叠、跳动或边缘裁切；多账号可访问 |
| UI-09 | 快速切换 | 连续切换图/签名/QQ 号原子一致；旧请求结果不覆盖新账号 |
| UI-10 | 展示隔离 | Dock 切换不修改 operationScope、不发注入/模型/消息请求 |
| UI-11 | 手动接入 | 进程 GET 只读，点击后携带 ProcessIdentity；重启不自动注入或监听 |
| UI-12 | 三种停止 | 暂停/停止监听/请求卸载文案、行为和结果分别正确 |
| UI-13 | 未知结果 | 注入/模型/发送未知结果明确，不能用自动重试制造重复副作用 |
| UI-14 | 账号范围 | 所有账号页面顶部可见范围；提交参数与所见账号一致 |
| UI-15 | 角色绑定目标 | accountId+kind+peerId 唯一，群聊/私聊分别显式选卡；界面不提供聊天历史或人工发送 |
| UI-16 | 草稿 | SSE/轮询不覆盖输入；离开/换账号处理未保存修改，失败保留输入 |
| UI-17 | 能力与授权 | 对话/识图/视频识别/生图/语音生成五项账号配置；从设置维护的服务中选择，无会话级模型覆盖 |
| UI-18 | 扩展范围 | 已安装、账号启用、会话可用、依赖缺失分别显示；普通选择不部署 |
| UI-19 | 规划功能 | 世界书/长期记忆/缺失制品接口明确不可用，不能保存后静默无效 |
| UI-20 | 凭据 | 读取仅状态/掩码；替换输入保存后清除，日志/导出/URL无密钥 |
| UI-21 | 本次测试结果 | 仅展示本次测试的图片/音频/文本，按账号鉴权并清理临时URL；不提供历史任务媒体列表 |
| UI-22 | 测试状态 | 等待/处理中/失败/取消/未知反馈明确；收费测试显式触发，视频为理解非生成 |
| UI-23 | 资源版本 | 公用/私有与固定/跟随版本清楚；部署失败逐账号展示，选择不执行 |
| UI-24 | 事件诊断 | 过滤和清空仅影响视图；脱敏；模型错误不误报QQ离线 |
| UI-25 | 路由 | 旧 hash 映射、新页面可直达、返回恢复筛选和选中项 |
| UI-26 | 原生窗口 | 标题栏不重复，拖拽/最大化/窗口控制正常，关闭到托盘行为正确 |
| UI-27 | 窗口缩放 | 1024×720、1280×800、1440×900；Windows100/125/150%下主要控件可达 |
| UI-28 | 键盘 | Tab顺序、可见焦点、弹窗Esc关闭及焦点返回、图标按钮有标签 |
| UI-29 | 对比度 | 正文与次文字实测4.5:1，控件/焦点必要图形3:1；状态不只靠颜色 |
| UI-30 | 动效 | 系统减少动效/轻量/关闭可用，快速输入可打断，隐藏窗口停装饰动画 |
| UI-31 | 数据状态 | 每个页面有加载/空/错误/陈旧/部分成功；接口失败不整页白屏 |
| UI-32 | 性能 | 大列表与媒体延迟加载，常用输入不卡顿，SSE不引发全页动画或重复订阅 |
| UI-33 | 偏好持久化 | 主题/动效/密度存储有版本，保存失败可见，账号偏好不相互覆盖 |
| UI-34 | 打包集成 | EXE中界面与源码预览一致；双QQ和真实服务场景有实际证据 |
| UI-35 | 无默认角色 | 每个群/私聊单独绑定；未绑定/缺卡不自动回复、不选第一张卡、不用账号旧卡兜底 |
| UI-36 | 多角色隔离 | 同账号群A/群B/私聊C可用不同卡；同数字群号与好友号、跨账号同目标不混用 |
| UI-37 | 切换角色 | 新轮次使用新绑定；旧运行中结果交付前校验修订，不误发旧角色回复；上下文按绑定隔离 |
| UI-38 | 语音闭环 | 语音schema/授权/适配器/测试/媒体均通过；TTS生成和QQ语音发送分别有证据，未配置不影响文字 |
| UI-39 | 旧配置迁移 | 旧会话模型覆盖冲突显式处理；旧账号角色不自动继承为所有会话人设；无静默行为变化 |
| UI-40 | 全局服务引用 | 稳定ID引用，删除引用中的服务有明确处理；修改影响账号可见；保存与选择不自动测试 |

交付证据：实际组件截图、关键流程录屏或可复现步骤、相关端到端/集成测试、缩放与可访问性结果、构建/打包日志。设计图与假数据不能代替 UI-34 的真实环境验证。
