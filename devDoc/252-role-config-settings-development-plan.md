## 2. 后端实施顺序

### 第一包 · 角色活动与配置写入保护

1. 梳理对话、Agent 任务、工具调用和自主调度的入口与可保存节点。按 DL-148 接入活动状态查询、停止与恢复。角色初始化状态和活动状态分别返回。请求停止后，当前活动到下一个可保存节点时保存进度并暂停，后端确认后才进入「已停止」。后续步骤不得启动。
2. 停止时仍未返回结果的节点按未完成处理，保留上一个已保存的进度。已发出的工具调用保留原调用记录，晚到结果归入原调用。无法确认结果时按 DL-53、DL-70 核查，恢复不能把已发送的操作重复发出。
3. 修改或删除角色配置前校验目标角色已停止。修改或删除全局模型服务前校验所有角色已停止。运行中和正在停止时拒绝写入并返回结构化原因。将状态校验与写入协调，覆盖校验与恢复并发的场景。恢复时待办和自主额度如何处理见第 4 节。

### 第二包 · 模型与扩展资源管理

1. 复用现有模型服务、模型 ID 和角色绑定，先以 API 跑通「建角色 → 配对话服务 → 保存绑定 → 启动对话并收到回复」。同时验收独立记忆模型及跟随对话。绑定接口目前替换整表，交付时明确调用方如何保留其他绑定；若支持并行编辑，补齐冲突保护。
2. 补全局资源删除及引用检查。删除前核对角色选择和相关运行限制，返回可供页面定位的资源、角色和拦截原因。独立的已保存模型条目及全局 TTS 目录是否纳入首包见第 4 节。
3. 对 MCP／Skill 的修改、删除和全局关闭同时检查角色开启与未结束任务链的使用权。关闭角色侧开关后，新任务立即不能使用；旧任务链按 DL-71、DL-73 保留使用权，结束后释放占用。资源列表和错误响应提供脱敏摘要，密钥和 MCP 环境变量值不进入选择器。

### 第三包 · 外观、删除与历史数据

1. 补服饰改名、主页立绘补传或替换、服饰及差分删除。批量导入保持 `standees` 与 `expressions` 两种来源。
2. 删除素材后将其移出衣柜和 Agent 候选。仍被历史引用的受管副本仅供原句段读取。替换立绘或同名重导后，旧句段继续指向原素材。若已有句段缺少原立绘标识，先确定旧记录的回退行为。
3. 角色删除支持「保留记忆与对话数据」和「一并删除记忆与对话数据」。保留时一并保留历史引用的受管素材；清理时清除该角色对应的数据和受管副本。两条路径都从管理列表移除角色，并保留用户源目录与源文件。删除当前项或最后一项的规则见第 4 节。

## 3. 语音与生图的交付边界

- 复用角色语音单份配置和试听接口。若确认首包加入全局 TTS，先交付服务关联、旧配置迁移、切换时的音色校验和资源删除保护。保存新配置覆盖该角色旧配置，停用时保留这一份配置。
- 复用 ComfyUI 文生图和已保存配置的样图接口。原型的未保存草稿出图和图生图锚点上传分别依赖新增接口，按确认范围实施。样图、试听不写入对话、记忆和正式演出记录，也不扣自主额度。
- 真实 TTS、ComfyUI 与 MOSS-Image 单独联调并留证。离线验收使用模拟服务。

## 4. 开发前仍需确认的决定

| 确认时机 | 内容 |
| --- | --- |
| 停止与恢复接口定稿前 | 恢复时如何处理待办和自主额度。停止边界及节点未返回的处理已记录在 DL-148。 |
| 模型接口定稿前 | 首包是否需要独立「已保存模型」条目、全局 TTS 目录。现有服务加模型 ID 足以先验收对话和记忆。 |
| 删除接口定稿前 | 删除最后一个角色或最后一套服饰、删除当前项后的回退，以及保留的数据从哪里读取。 |
| 样图接口定稿前 | 是否支持未保存草稿出图，以及图生图是否纳入此次交付。 |

## 5. 后端验收与交接

| 场景 | 通过条件 |
| --- | --- |
| 停止与恢复 | 任务在可保存节点暂停，后续步骤未启动。未返回的节点保持未完成，晚到结果归属正确，恢复不会重复执行已发出的操作。 |
| 写入与占用 | 正在停止时拒绝写入。任一角色未停止时拒绝全局模型修改和删除。任务链仍占用扩展时拒绝修改、删除和全局关闭，释放后允许。 |
| 配置闭环 | 新建角色、保存服务与绑定、按需要恢复活动后可正常对话。配置写入互不覆盖，记忆模型继承来源清楚。 |
| 删除与历史 | 新衣柜与 Agent 无法选到已删除素材，保留的历史能读原图。角色删除的两条数据路径都保留源文件。 |
| 语音与生图 | 角色语音始终只有一份当前配置；停用期间可试听。文生图按目标服饰取提示词，纯背景只传环境描述。 |

当前后端范围实施完成后，记录类型检查、定向用例、`npm run accept:offline` 和独立复核。交接时提供可用接口、请求和响应结构、状态与错误码、仍未开放的能力。后端独立复验通过后，开始 253 的页面接入与桌面联调。
