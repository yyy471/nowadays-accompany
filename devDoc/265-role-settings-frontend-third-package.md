# 角色配置与设置前端第三包接入记录

2026-11-11。依据 [253](253-role-config-settings-frontend-plan.md)、[262](262-role-appearance-deletion-history.md) 和 [263](263-role-appearance-deletion-independent-review.md) 接入已验收后端接口。本轮只修改桌面前端与测试；本记录为实现方自验，独立复核另行执行。

## 接入内容

- 角色删除要求角色已停止并至少保留一个角色；必须显式选择保留本机历史或清理角色目录，分别传递 `keepHistory=1`／`0`。删除当前陪伴角色后，列表刷新并切到仍存在的角色；后端返回文件尚未清理时保留提示。
- 衣柜提供服饰改名、主页立绘补传／替换、差分预览与删除、服饰删除及最后一套保护。外观写入只在目标角色已停止时开放，保留原有导入和差分上传。
- 对话句段读取 `homeAssetId` 和 `spriteAssetId`，按素材 ID 回放；服饰更换或素材移出衣柜不改变已有句段的素材指向。没有服饰快照时不显示替代立绘，差分不跨服饰沿用。SSE 标注同时合并主页立绘快照。
- 模型服务增加全局启停、删除和占用提示，修改或删除受全角色停止保护。模型、MCP 或 Skill 删除后，已打开的角色配置刷新绑定及版本，清除已删除资源的选择，保留其他草稿；刷新失败时禁止保存并允许重试。
- 完成度中的设定状态依据已保存快照，而非未保存的人设草稿。
