# 独立世界书与条目管理：完整验收标准

日期：2026-10-23。状态：待执行。对应[46 实现方案](46-independent-worldbook-implementation-plan.md)。以下所有“应当”都是目标，不是当前通过记录。

## 1. 执行规则与测试环境

自动测试使用独立临时dataRoot、FakeChannel/FakeProviderAdapter，不依赖真实QQ、SnowLuma或付费模型。前端真实浏览器验收启动同样的隔离控制服务。Electron原生与真实QQ作为单独人工验收，不得用浏览器结果替代。

固定测试资料：账号A/B；A的私聊P、群聊G及另一个私聊Q；显式角色R带内置条目embedded；独立书W的r1/r2（关键词花园、不同正文）；独立书V（常驻条目）；空书E；含不支持规则的酒馆样例；错误JSON、超限文件与路径异常样例。所有ID与端口仅在测试环境使用。

执行前记录Git状态、Node版本、命令与日期；保留既有未提交修改。测试失败须给出最小复现与修复，不能删除断言或加skip绕过。现有基线为78文件、663通过、1项既有权限相关跳过；新实现应增加有意义的回归测试，不将基线数量当作新阶段固定数量。

分级：P0为隔离/静默错误生效/覆盖与丢数据，P1为主链路或故障恢复错误，P2为布局/可访问性/提示等。P0、P1必须全部通过；影响基本操作的P2也必须修复。其他P2若延期需明确列出影响与处理计划。

## 3. 资源提交与文件失败

| ID | 级别 | 操作/故障 | 预期 |
| --- | --- | --- | --- |
| S01 | P1 | 预览导入、取消选择、关闭预览 | 不创建正式目录、catalog或会话配置 |
| S02 | P1 | 预览后修改/替换源文件 | 指纹复验失败，要求重新预览，不提交旧预览 |
| S03 | P1 | 超过读取上限或HTTP体上限 | 有界拒绝；不先整体读入/解析巨大输入 |
| S04 | P0 | 写临时文件/校验/rename失败 | 不出现可见的半个revision；错误不冒充成功，原版本和绑定不变 |
| S05 | P0 | 相同id/revision并发不同内容 | 至多一个成功，另一个409；不能覆盖已发布内容 |
| S06 | P1 | 同一requestId、revision、内容重试，含响应丢失 | 返回同一结果，不产生重复版本或错误覆盖 |
| S07 | P1 | 同requestId或目标revision换内容重试 | 明确冲突，不接受为幂等成功 |
| S08 | P1 | 同一基础版本派生不同revision并发保存 | 两个新版本可独立保存，原基础不变，不宣称互斥CAS |
| S09 | P1 | 基础版本被外部修改后派生 | expectedBaseFingerprint冲突，保留编辑草稿 |
| S10 | P1 | 资源保存成功但列表刷新失败 | 提示已保存及刷新失败，不自动生成另一版本 |
| S11 | P0 | 所有导入/编辑保存操作 | 不自动修改任何账号绑定、开关或当前角色 |
| S12 | P1 | 服务退出时存在写请求 | 已准入任务按既有机制排空，新任务拒绝；无新私有队列逃逸 |

文件故障应使用可注入文件操作/真实临时目录做可重复测试；不要依赖chmod在Windows必然生效。临时目录清理先验证绝对路径和前缀，不能删除真实dataRoot。崩溃遗留的受控临时目录不得当作正式资源列出。

Electron人工清单（独立记录，不默认通过）：

1. 启动最新构建的桌面程序，确认版本与构建时间，避免误用旧release EXE。
2. 原生选择器选中文件、取消、中文/空格路径、文件在预览后变化，均符合方案。
3. 编辑草稿、窗口隐藏/恢复、托盘真实退出、忙碌退出与退出后重启，状态符合现有退出契约。
4. Windows常用缩放下验证编辑器、会话选择器和弹窗滚动/键盘/焦点。
5. 单独准备测试QQ及自有会话，人工点击连接/监听后确认固定世界书参与提示词；只对测试对象发消息。是否发送真实消息按执行当次授权，不作为本方案默认执行动作。
6. 模拟独立书损坏，确认该会话提示与恢复，其余会话保持正常；完成后恢复测试数据。

人工步骤未完成时，可结论为“实现与自动/浏览器验收通过，原生/真实QQ待验收”，不得写成完整发行验收通过。
