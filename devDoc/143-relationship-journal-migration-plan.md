# 143 关系页原貌迁移方案与采用范围

2026-10-28。用户要求开始迁移 `wiring-journal-radio-v3`，并明确尽量保留原 HTML。目标为全局 Dock 第二项 `roles`，不改其他业务页设计。

## 采用与边界

采用白昼手账/复写纸、晚风电台、账号书脊/机架、会话索引/刻度、角色人像区、能力贴纸/设备、来源透视、日间小样/夜间频谱总览及原材质、装饰字体。日夜总览表达差异作为关系页专项扩展，切换保持账号、会话、筛选和草稿。

应用壳、品牌、设置、Dock、确认、Modal、导航和退出协议继续复用现有实现。原型脚本全局状态、模拟保存、模拟授权与安装不进入生产；真实状态由已有服务与共享生效解析器提供。实际角色没有封面时使用明确标注的示意图，不冒充真实头像。

素材及CSS参考冻结到 `devDoc/design/relationship-journal/reference`。纸纹、阴影、复写色、字体等新增值登记为 relationshipJournal 三层 token，样式限定 `.wj-journal`。允许在公共控件上增加关系页限定外观，页面不另建基础组件库。原完整窗口主题快照不复制；局部动效消费公共策略，并保留主要动作表达。

昼夜切换复用唯一 `ThemePresetProvider` 状态，由当前 `roles` 页注册临时专属表现策略；全局天气换场只在未注册关系页策略的页面运行。关系页主题立即提交，页面真实DOM做原稿暗场/晨光收束；右页规则线与刻度按DOM实测几何作短划、升起和逆向落线形变，总览只处理纸面/设备材质。局部减少动效、强制颜色、隐藏窗口、关系页DOM缺失及动画错误均直达最终预置；快速反向、离页和偏好变化要清理动画与装饰。实施证据见[146关系页昼夜切换执行记录](146-relationship-journal-theme-transition-execution.md)。

## 实施包

1. 冻结参考、增加 token 与局部外观；保留原 DOM 类名及 SVG 素材。
2. 新增 React 关系页、账号/会话/资源模型和草稿控制器，接入 `roles`。原 AccountsPage 作为资料/世界书及兼容深链接的可达编辑入口。
3. 对接账号、绑定、制品、会话记录、扩展策略、能力预览与回复策略。会话名册以明确配置对象为依据，历史会话作为候选，不承诺全量联系人。
4. 角色绑定与能力策略明确分开提交；扩展使用 revision CAS，未知结果核对而不自动重提。跨账号迟到响应不得覆盖当前上下文。
5. 双主题/多尺寸浏览器对照、回归测试、typecheck、全量测试、desktop build、token check；执行记录与独立复核分别落文档。

## 验收重点

- 正式应用壳中的主构图、素材、字体、材质及日夜不同总览与参考对照。
- 无账号、加载、失败、空会话、无角色、未就绪、未授权与旧数据状态真实可辨。
- 三层继承、明确关闭、恢复跟随、预览与已保存状态区分。
- 保存失败保留草稿；冲突不强制覆盖；部分成功与未知不显示整页成功。
- 账号切换、离页及退出经过现有草稿准入；主题不卸载页面、不写业务配置。
- 资料编辑、世界书、已有 focusDisplay/focusBinding 可达。
- 不启动 QQ/SnowLuma，不发真实消息或调用模型进行界面验证。
