# 接线 · 手账 / 电台 概念原型（v3）

> v1、v2 分别备份在 `/workspace/wiring-journal-radio-v1/`、`/workspace/wiring-journal-radio-v2/`。v3 在 v2 基础上修掉了 v2 自己列出的弱点和遗留问题（见下方「v3 · 修复清单」）。本包只含原型本身，不含截图和录屏。所有数据都是虚构的示例，界面上标着「示例数据」。

打开方式：用 Chrome 或 Edge 直接双击 `index.html`（file:// 即可，不用联网）。也可以在地址后加 `#theme=nightwave` 或 `#motion=reduced`。界面上的账号、群号和人名全部是虚构的示例数据，改动只存在页面内存里。

## 核心隐喻

- **白昼来信**：每个 QQ 账号是书架上的一本手账，每个会话是一页。
  - 页首贴着谁的人像，就是谁在说话。
  - 右页贴着的贴纸，就是带着的本事。
  - 用红笔圈出来的，是开了却用不了的，旁边写着原因。
- **晚风电台**：每个账号是一台收音机，每个会话是一个频率。
  - 主持人在麦前说话，推子槽里插着设备。
  - 故障灯亮着就说明有问题，旁边有原因标签。

### 三秒内能看出什么

| 问题 | 看哪里 |
|---|---|
| 谁在说话 | 左页人像和落款章「会回复 / 不会回复」（夜里是 ON AIR 灯） |
| 带着什么本事 | 左页中段的「带着」清单，右页的贴纸或推子 |
| 为什么有的用不了 | 红笔批注或故障标签。点一下就跳到能修的地方 |

### 分层是怎么表达的

分层就是复写纸：
- 扉页（账号通用）和分类页（群聊 / 私聊）上写下的内容，会印到后面每一页上，显示为淡紫色的虚线复写印。
- 本页自己贴上的是实墨。
- 揭下表示本页关闭。
- 用橡皮擦掉表示恢复跟随上一层。

按住空格「掀纸透光」，能看到每一层各写了什么，以及最后生效的是哪一层。

## 日夜对照

两套主题的骨架完全相同：布局、信息层级、操作位置和键盘路径都一样，换的只是隐喻的皮。

| 概念 | 白昼来信（手账＋复写纸） | 晚风电台（调频） |
|---|---|---|
| 账号 | 书架上的一本手账，书脊上的腰封标明在线或未连 | 机架上的一台收音机，带 LED 和状态 |
| 会话 | 一页，用索引页签 | 一个频率，刻在表盘上 |
| 通用 / 分类层 | 扉页、分类页 | 总台、群聊分台 / 私聊分台 |
| 角色卡 | 页首的拍立得人像；空的是虚线框「还没请人来」 | 主持人；空的是「空麦克风」 |
| 插件和 Skill 的来源 | 封底的整版贴纸 | 设备架 |
| 开启 | 把贴纸贴到右页，显示为实墨 | 把设备插进推子槽，显示 ON AIR |
| 跟随 | 复写印，标明来自哪一层 | 转播，标明来自哪一台 |
| 关闭 | 揭下，留下残胶，并写明「底下透着什么」 | 拔掉推子，并标明「上级是什么」 |
| 恢复跟随 | 橡皮擦 | 切回转播 |
| 开了却用不了 | 红笔圈加批注 | 故障灯加原因标签 |
| 看层级来源 | 掀纸透光（按住空格） | 信号来路（按住空格） |
| 反查 | 并入「摊开全本」：点一个角色卡、插件或 Skill，用到它的页亮起 | 并入「全频扫描」：点一个设备，用到它的台亮起 |
| 改公共定义前 | 先看影响：会改到哪几本、哪几页 | 先看覆盖范围 |
| 换账号 | 合上这本，换一本翻开 | 关机，换一台再开机 |
| 换主题 | 页面暗下去，纸上的横线升起来变成调频刻度 | 刻度落回纸面，变回横线 |

## 自评一句话

据我所知还没有人这么做过：用复写纸讲「继承」，用转播讲「跟随」，而且日夜两套是同一副骨架、两层皮，切换时线条会形变过去。哪里还不够好，见下面的已知问题。

## v2 · 总览：「摊开全本 / 全频扫描」

**入口**
- 右上工具区第一个按钮，名字和隐喻跟着主题走：白天叫「摊开全本」，夜里叫「全频扫描」。
- 快捷键 O 打开或关闭总览。I 是 v1 索引页的旧习惯，也能打开总览，因为索引已经并进来了。
- 按钮上有 6 格小样图标，副标题写着「总览全部会话」，第一眼就知道它是干什么的。

**隐喻**
- 白天：把整本手账摊在桌上，每一页缩成一张缩略小样，像印刷厂的样张。
  - 红笔圈出问题；荧光笔标出用到某项的页；没用到的页压成灰纸。
  - 全部账号时，几本手账并排摆开，中间用布书脊隔开。
- 夜里：一次扫完整个波段，每个台一格。
  - 显示频率、主持人、ON AIR 或 OFF、故障灯；
  - 选中的设备让用到它的台亮起橙框，其余台压暗。
- 两套主题是同一副骨架：顶栏、故障条、左栏、小样墙，操作完全一样。

**每张小样都回答这几件事**
- 谁在说话：角色卡头像和名字；没有角色卡时显示「还没请人」或「无主持」。
- 回不回复：「会回复」或「不会回」印章 / ON AIR 或 OFF。
- 带着什么：一排设备小格，实色表示开，叉表示关，空心表示跟随上层。
- 自己写了几处还是全跟随：右上角写「自己写了 N 处」或「全跟随」。
- 问题在哪：最多两条红笔原因，比如缺授权、未就绪、账号离线。
- 本页揭下了什么：放在右侧角落。

**页面结构**
- **故障条（红笔圈出 N 处）**：按原因归类，每类写出影响多少页。点一下，受影响的页亮起，其余压暗；再点一次取消。
- **左栏筛选**：全部、有问题、自己写了、全跟随、不会回复，每项带数量。
- **左栏资源**：角色卡、插件、Skill 各一组，每项写明在每个账号用了几页。
  - 点一项进入聚焦：用到它的页亮起；本页揭下（关）的页另画一种虚框，没用到的压暗。
  - 聚焦面板可以展开「改公共定义前先看影响」。
- **搜索**：按 / 进入，可以搜页名、页码或频率、角色、群号。Esc 先清空搜索，再按一次退出搜索。
- **账号范围**：「只看当前本 / 全部账号」，快捷键 A。
  - 全部账号时，每个账号是一本独立的书，有自己的扉页条和统计。
  - 账号之间用书脊（夜里是一条色光竖线）隔开，结果绝不跨账号合并。这是红线「账号是孤岛」在总览里的体现。
  - 每个账号不超过 10 个会话时，几本书并排摆；会话多时，改成上下叠放，书脊变成横向分隔。
- **翻页与返回**：
  - 点小样或按 Enter 就翻到那一页。View Transition 让小样放大成整页。
  - 页面左上会出现「← 回到全本 / 回到全频扫描」。回去时，滚动位置、范围、筛选、搜索、焦点全部原样恢复。

**动效**
- 打开：当前整页缩回它自己的小样（共享元素 `wj-page`），其余小样按离它的距离一圈圈涟漪浮现。
- 关闭：反过来，小样放大回整页。旧快照提前淡出，避免放大后的模糊位图停留。
- 减少动效时，`--m=0`，直接切换，没有位移。

**键盘**
- 总览内：
  - 方向键按空间位置在小样（夜里是光柱）间移动，可以跨书 / 跨账号波段移动；夜里 ↑↓ 一次跳 6 根；
  - Home / End 跳到首尾；
  - Enter 翻页；
  - / 搜索；A 在「当前账号 / 全部账号」间切换（范围条上也能直接点 A、B、C 任一账号）；O 或 Esc 关闭；
  - Tab 依次走过顶栏、故障条、左栏、小样墙。
- 打开总览时，焦点落在当前页的小样上；关闭后，焦点回到页标题。

## v2 · 弱点修复清单

1. **白天的书架和页签有了真材质。**
   - 书架：木板有纹理和书挡。
   - 书脊：布纹和颗粒纸两种，高矮不一，有堵头布和起脊线；书名是烫金字，外面套一条手写的纸腰封；当前那本挂着书签丝带。
   - 页签：改成半透明胶片索引签。分层页用牛皮色，群聊用粉色，私聊用灰绿色。
2. **白天切夜晚的前 100–200ms 不再乱。**
   - 快照前先把纸面横线换成精确颜色的形变层（`data-txpre`）。
   - 先静止 180ms，再从左到右一道波：横线 → 虚线 → 升起 → 刻度。
3. **头像更好看了。**
   - 改成 riso 双色印刷风格，6 种造型：店员、主持、邮差、守夜人、园艺、广播员。
   - 每种有网点、套印错位的发型层和专属小图案。夜里加 duotone 滤镜。
   - 全部是 SVG 生成的风格化人物，不对应任何真人。
4. **40–60 个会话也放得下。**
   - 演示开关（Ctrl+Shift+D）可以切换「大量会话（60 个）」。A 本有 30 个群聊和 16 个私聊。
   - 超过 12 页时，页签折成小旗，刻度折成小点。
     - 问题页带红点；没有角色卡的页颜色变淡。
     - 悬停或聚焦时浮出名字；分区标签带数量。
     - 当前页的名字压到分区标签时，分区标签自动让位。
   - 页签和刻度用 roving tabindex：方向键、Home、End、PageUp、PageDown 都能用。
5. **提示不再盖住表盘。**
   - 提示移到左下角，宽度不超过半屏减 230px。
   - 白天做成一张小票，夜里做成 LCD 条。
   - 显示时长按字数计算。
6. **1366×768 和 1280×720 下左页不再滚动。**
   - 为 ≤820px 和 ≤760px 高度做了两档紧凑布局。
   - 逐页、逐账号检查过，溢出为 0。
7. **对比度达标。**
   - 用脚本对 16 个状态（两套主题 × 主屏、底稿、揭下页、无角色页、总览、聚焦、全部账号、演示开关）的 2449 个文本元素做了像素采样。
   - 结果 **0 个不达标**：正文 ≥4.5:1，大字 ≥3:1。
   - 复写印文字改用专门的 `--carbon-ink`，残胶和揭下页也提亮了。
   - 例外：烫金书脊字用的是 `background-clip:text`，脚本测不了。它旁边都有可读的文本或 aria 标签。

## v2 · 其他打磨

- **保存有四种结局。** 用隐藏的演示开关「下一次保存的结果」切换。
  - 保存中：墨点 / 信号搜索。
  - 成功：白天盖「落款成功」章，夜里显示「信号确认」ACK。
  - 失败：草稿保留，焦点回到保存按钮，写明原因。
  - 结果未知：不假装成功，给出「核对一下」按钮，焦点落在上面，核对后回到空闲。
- **演示开关**：数据集、下一次保存结果、动效（跟随系统 / 完整 / 减少）。界面上标着「只给评审用」。也可以用 hash 参数：`#data=big&ov=1&theme=nightwave&motion=reduced`。
- **右上角数据标签**：显示「示例数据」，切到大数据集时显示「示例数据 · 大量会话」。
- **读屏**：结论句另有一份 sr-only 全文；离开总览后焦点回到页标题；大量会话时页面注释最多列 14 页，其余引导去总览。
- **字体子集**：按 v2 新增的文字重新生成了子集（手写体约 340KB，标题体约 300KB，WOFF）。

## v3 · 修复清单

1. **夜间「全频扫描」换成真正的频谱 / 瀑布图**（不再是卡片网格）
   - 每个台是一根光柱，按频率从左到右排在刻度上。柱高 = 接入设备数，每一格是一台设备：亮琥珀 = 本台直播，暗格 = 转播，空框 = 本台关，红格 = 故障。
   - 柱顶是信号灯（绿 = 会回复，暗 = 停播，红 = 有故障）；柱底的三格「瀑布」分别是总台、分台、本台各自贡献了几路信号。
   - 一道扫描线从左往右慢慢扫过（减少动效时不显示）；当前收听的台有一根红色指针和「收听中」标签。
   - 右侧是 LCD 读数面板：频率、台名、主持人、回不回复、故障原因、设备清单，加「调到这台 Enter」。焦点或悬停到哪根光柱，读数就跟到哪根。
   - 保留了所有功能：点击 / Enter 调台；筛选；资源聚焦（命中的柱亮起，其余变暗，开着但用不了的单独标出）；搜索；方向键 + Home / End；全部账号（每个账号一条独立波段，账号仍是孤岛）。
   - 会话多到每根光柱不到 14px 宽时，台名只在当前 / 读数 / 悬停 / 聚焦时浮出，不再挤成一团。
   - 白天的「摊开全本」功能完全等价，没有改动交互。
2. **当前页签不再盖住旁边的小旗。** 页签改成「推开」布局：当前页签位置不动，左右的小旗按需要的间距让开（带一段短动画），窗口缩放时重新计算。
3. **1280×720 不挤了。**
   - 右页按自身宽度排版（container query）：设备格改成确定的三列小网格，来源胶囊过长时省略，窄卡片里编号给名字让位。
   - 矮屏（≤820px 高）打开总览时，总览盖满整个舞台，顶部书架和页签暂时退出（并设为 inert，键盘不会走进去）。白天一屏能看到约 3.5 行 × 4 列小样（v2 只有 2 行）；夜里整条频谱一屏放下。
4. **账号切换和总览缩放用同一套空间语言。** 账号切换也改成 View Transition：旧的整本书缩回它在书架上的书脊（夜里是收音机按键），新的书从它的书脊放大成整页，和「整页 ⇄ 小样」的缩放是同一个模型。不支持时退化成同方向的 2D 缩放；减少动效时直接切换。
5. **保存冲突**（别处同时改了同一处）
   - 演示开关（Ctrl+Shift+D）里「下一次保存的结果」新增「冲突」。
   - 冲突时右页弹出对照面板，逐条列出「你的 / 对方的」值，可以逐条选，也可以「全用我的 / 全用对方的」，然后「按选择落款 / 发送」，或者「先不落款」。
   - 白天是两张复写纸条：你的是蓝墨，对方的是复写印、微微错开；没选中的那张被划掉。夜里是两路信号：选中的那路亮 ON AIR 灯，标题是「同频干扰」。
   - 键盘：出现时焦点落在第一条「你的」上；Tab / Enter 选择；Ctrl+S 按当前选择落款；Esc 先不落款。采用对方的值会真的写回数据，结果在提示里写明（例如「保留你的 0 处，采用对方的 1 处」）。
6. **「没安装」有了安装入口。**
   - 点红笔批注 / 故障条（或在格子上按 Enter），会打开封底 / 设备架，最上面列出「没安装，但有页开着它」，并说明有几页因此用不了。
   - 安装面板写明会做什么：装进这本的封底；如果这个 Skill 需要权限，默认勾选「同时授权」（可以取消）。
   - 按「安装到 C 本（模拟）」→ 安装中 → 装好后批注被划掉 / 故障灯熄灭，提示里写明结果。如果取消了授权，会如实留下「缺授权」这条原因，而不是假装能用。
   - 示例数据里 C 本的群聊分类页开着「群文件助手」但没安装，可以直接体验。
7. **不支持 View Transition 时平稳退化。** 所有过渡都走同一个入口 `startVT`：API 不存在、减少动效、页面在后台、或调用抛错时，直接同步更新，并给账号切换一个 2D 兜底动画。演示开关里可以切到「模拟不支持」。测过删掉 `document.startViewTransition` 后切主题、开关总览、切账号，均无报错，状态保持。
8. **Windows 真实环境**
   - 字体回退：正文 / 标题 / 等宽依次回退到 Segoe UI Variable → Microsoft YaHei UI → Microsoft YaHei → PingFang SC → Noto Sans CJK SC；手写体和标题体打包了子集 WOFF，回退到楷体 / 宋体。用一套更宽的拉丁字体做过压力测试，没有新增溢出。
   - DPI：按 125% / 150% 缩放后的有效视口 1536×864、1280×720、1024×640 逐页逐账号检查。内容不再被裁掉：放不下时左页整体可滚，右页只滚设备格（页眉和封底条固定）。新增 ≤1100px 宽的布局（窄书架、窄工具栏、页签名字收字号）。
   - 发丝线：启动时按 `devicePixelRatio` 计算 `--hp`（整数个物理像素）和 `--px`。纸面横线、复写纸横线、频谱网格的线宽和间距都对齐物理像素，125% / 150% 下是一条清晰的线，不再糊成两行。
9. **标题字体「回」字修好了。** 原站酷小薇字体里「回」少了内框、外框方向也错了，渲染成实心块。v3 重建了这个字形（反转外框、补上内框）后重新生成子集，浏览器里验证显示正常。
10. **其他打磨**
    - 冲突时不再额外盖印章，免得压住对照面板。
    - 夜间读数面板的设备清单在内部滚动，「调到这台」按钮始终可见（720px 高时以前会被挤出去）。
    - 范围条改成每个账号一个按钮 + 「全部」，带在线状态点。

## 已知问题（诚实版，v3）

- **1024×640（1280 宽屏开 125% 缩放）仍然偏紧**：右页一屏只能看到两行多设备格，需要在格子区内滚动；个别四字页签名会显示省略号（悬停 / 聚焦可看全名）。这个尺寸能用，但不算舒服。
- **全部账号的频谱**：矮屏下一屏大约只放得下 1.3 条账号波段，要往下滚；最右侧波段标签在极端情况下会被截掉末尾几个字。
- **冲突和安装都是模拟的**：冲突内容由演示开关生成（最多 3 条），没有接真实的版本号 / 合并逻辑；安装是在内存里把资源加进封底，没有下载、版本、依赖解析和失败状态。
- **账号切换的 View Transition**：只在无头 Chrome 里实测过（Edge / WebView2 同为 Chromium 内核，预期一致，但没有实测）；其他内核走 2D 兜底。打包后的 exe 里还没实测。
- **Windows 真机**：字体回退和 DPI 是在 Linux 无头 Chrome 里用设备缩放比和替代字体模拟的，没有在真的 Windows + 微软雅黑 + ClearType 下看过；发丝线对齐在窗口拖到不同缩放比的显示器上时依赖 `resolution` 媒体查询重新计算。
- **读屏**：频谱光柱有完整 aria-label，但还没用 NVDA / 讲述人实机走一遍。
- **减少动效**：印章在减少动效下的规则仍分散在几个 CSS 文件里，后续应该收拢。
- **数据结构只是示意**，不对应真实后端。
