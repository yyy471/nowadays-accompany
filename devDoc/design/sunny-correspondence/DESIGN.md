# nowadays · 晴日通信

桌面端视觉与交互设计提案 · 2026-10-27

## 设计立场

这是一个替年轻用户安放数字陪伴的桌面应用。首页应该让人愿意回来，配置页应该让人知道下一步怎么做。

以「日常通信」为视觉母题：一张有生活气息的海边插画、一份简洁的账号资料、像书架一样的角色收藏。把人和关系放在前面，把运行细节留在它们真正有用的地方。

这次只读取了项目文档与设计技能说明，没有读取项目业务代码。全部新增文件位于本文件所在目录，未修改或替换现有前端、后端和 EXE。

## 品牌与美术指导

**气质：亲近、有自己的生活、安静但不寡淡。**

不采用营销官网的首屏结构；不使用业绩指标、三张功能卡片或数据仪表盘。首页的主视觉是一扇望向日常的窗，右侧直接呈现账号、连接、自动回复和继续操作入口。插画承担情绪，操作区保持稳定、可读。

画面中的年轻人、白猫、海风与收音机表达「陪着做普通的事」。它们不是功能隐喻，也不是要用户点击的装饰控件。配置页收起大幅插画，把空间交给操作本身。

角色库采用书封和书架的语法，体现稳定设定、固定版本与收藏关系。书架四列中包含导入位置，不是把所有功能塞进卡片网格。

## 色彩

所有颜色集中在 `tokens.css`，按语义命名。

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 纸白 | `#FAFAF6` | 主阅读底色，减少冷硬感。 |
| 雾灰绿 | `#F0F1E9` | 常驻导航，与内容区产生轻微空间差。 |
| 墨色 | `#252E2C` | 主文字、当前导航，不使用大面积纯黑。 |
| 次级文字 | `#68716A` | 辅助信息和说明；重要操作不用浅灰表达。 |
| 朱橙 | `#BB452D` | 保存、进入工作台等主要动作及当前标签。 |
| 海盐青 | `#DCE9E4` | 角色预览、陪伴状态与轻提示背景。 |
| 深海青 | `#356859` | 连接可用、明确的就绪状态。 |
| 日光琥珀 | `#F2B84A` | 品牌小记号，延续既有日光意象。 |

状态同时使用文字；不会只靠红绿区分。连接、自动回复、绑定和模型各自表达，避免一个「在线」掩盖多个不同的状态。

## 字体、排版与尺寸

- 桌面基准：1440 × 960；同时检查 1280 × 800。
- 字体：英文优先 Segoe UI Variable；中文使用 Windows 原生 Microsoft YaHei UI。免网络加载，也不增加 EXE 的字体包体。叙事签名和角色封面少量使用中文衬线字体，回退至系统宋体。
- 品牌字 23 px；页标题 29 px；区块标题 20 px；内容与操作 12–14 px；辅助信息 10–12 px；签名 17 px、1.9 行高。配置型桌面软件采用紧凑辅助文字，长正文不使用该字号。
- 数字 ID 与版本使用 Cascadia Code / Consolas，只用于需要准确辨认的短信息。
- 页面左侧固定导航 204 px；内容左右留白 40 px；主要分区间隔 24–32 px。
- 圆角按对象分层：输入与按钮 6 px，功能编辑区 12 px，首页展示区 18 px。头像使用圆形，角色书封接近直角。
- 用留白、底色和细分隔线表达层级，不在每个元素外面再加一层卡片。

## 页面稿

| 页面 | 主要任务与版式 |
| --- | --- |
| 主页 | 左插画、右当前账号；下方是另一个账号的轻量行。进入工作台是主要动作，暂停回复是次要动作。 |
| 总览 | 连接、绑定、模型三步准备清单与当前陪伴状态。每一步都能直达对应页面，不使用无意义的统计卡片。 |
| 实例与监听 | 当前账号的 QQ 身份、监听、自动回复、外部服务状态；右侧提供短步骤。停止监听有明确影响说明。 |
| 资料与角色 | 默认进入会话角色；左侧搜索与绑定列表，右侧角色及世界书设置。账号展示位于次级标签。 |
| 插件与 Skill | 标签分开工具与方法，顶部明确应用范围；媒体工具独立授权；新建 Skill 默认关闭。 |
| 模型配置 | 五行能力配置与右侧测试区；服务、模型、启用和测试按顺序排列。保存与测试是独立动作。 |
| 事件诊断 | 按时间展示可理解的结果与原因；技术信息按需展开；不展示聊天历史。 |
| 资源库 | 角色卡、世界书、插件、Skill 分类；角色和设定采用书封；导入先预览，再确认。 |
| 应用设置 | 模型服务、外观与动效、SnowLuma、数据与安全、关于。全局连接信息只设置一次，账号页快速选择。 |

保留文档规定的九页结构，但让「工作台」作为导航分组，而不是额外的一页。资源库与设置固定在导航底部，便于建立空间记忆。

## 交互与动效

- 普通按钮：140 ms 的颜色反馈，按下移动 1 px；不悬浮放大。
- 页面切换：240 ms、5 px 的轻微上移和透明度过渡，帮助确认切换完成。
- 角色书封：仅悬停上移 5 px，表达可以翻阅。
- 开关：拇指位置平移；文字状态始终可读。
- 焦点：立即显示 2 px 朱橙描边；不对焦点淡入。
- 减少动态效果：响应系统 `prefers-reduced-motion`。设置页还提供演示用动效开关。
- 草稿：修改后切换页面、切换账号或选另一个目标时，出现「继续编辑 / 放弃修改 / 保存并离开」。关闭浏览器时也提示未保存内容。
- 测试：明确进入测试中，暂时禁用触发按钮，结果只出现在临时区域。
- 空态：目标搜索无结果有独立表达，不与连接失败混用。
- 弹窗：使用浏览器原生 dialog，限制焦点、支持 Esc 关闭。

## 原型范围

`index.html` 是可双击打开的离线设计原型。它包含 9 个可切换页面、账号切换、角色筛选与预览、开关、模型示例反馈、服务表单、诊断展开和草稿保护。

账号、QQ 号、时间、引用数量、资源内容与运行状态均为虚构示例，页面已标注。原型中的保存仅用于本次演示；刷新后复位。它不会连接 QQ / SnowLuma，不读取消息，不调用模型，不保存真实密钥，也不改变现有系统。文件导入入口只演示选择与预览位置，不解析文件。

记忆管理页面、情绪数值、遗忘曲线、浏览器任务与跨账号管道没有添加入口。正式实现前还需补齐真实接口的加载、请求失败、资源缺失、版本冲突、付费测试确认和权限状态；不能用本设计稿的示例交互代替运行验收。

## 交付文件

- `index.html`：原型入口。
- `nowadays-design.html`：把样式、交互和插画打包在一起的单文件离线版本，便于直接打开或转交。
- `tokens.css`：统一颜色、字体、圆角与动效变量。
- `prototype.js`：与现有项目独立的示例交互。
- `sunroom.png`：ImageGen 内置工具生成的原创插画。
- `ART-PROMPT.txt`：用于生成插画的最终提示词。
- `preview-home.png`、`preview-roles.png` 等：真实浏览器渲染的页面截图。
- `design-board.jpg`：关键页面总览板。
- `review.json`：自动布局及交互检查结果，检查内容与局限以文件为准。

本稿选用 Windows 原生字体服务桌面易读性；保留文档产品边界，未套用网站模板。自评：概念 5 / 层级 5 / 细节 4 / 产品针对性 5 / 克制 5 / 结构差异 4。正式前端接入与 EXE 打包不属于本次设计稿交付。
