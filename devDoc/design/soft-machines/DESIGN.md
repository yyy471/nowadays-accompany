# nowadays / SOFT MACHINES

桌面玩具 · 第三套美术方向 · 2026-10-27

## 方向

把界面想成一张摆着喜欢的东西的桌面。角色是一件可触摸的装置，控件像能按下去的实体按钮，设置像打开一个小抽屉。

与「私人频段」的漫画印刷、暗色舞台和细线接线相比，这套使用奶油白的开放空间、钴蓝与橘红、哑光玩具材质、圆润字形、按压深度和底部导航。它表达明快、亲近和一点机灵；仍然面向年轻成年用户。

## 三个核心画面

| 页面 | 空间与交互 |
| --- | --- |
| 桌面 / 主页 | 左侧为波比角色装置，右侧为当前账号、签名、工作台入口和回复控制。顶部切换账号，下方是已安排的关系。 |
| 关系 / 资料与角色 | 一份连续的配对名册；点击某个目标就在原位置展开角色、世界书与保存操作。右侧提供波比的角色视觉样本。 |
| 模型 / 能力配置 | 五个可展开的能力抽屉，一次专注一项。服务、模型、开关和测试放在同一抽屉里，不必在另一块面板寻找对应项。 |

底部常驻四个常用入口和「更多」。桌面尺寸为导航保留独立空间，长配置页在内容区内滚动；窄窗口采用底部固定导航，页面预留底部空间。

## 视觉语言

- **品牌**：保留 nowadays 与 n 加日光点的识别思路，换成钴蓝字标和橘红记号；是方向稿示意，未替换正式 Logo。
- **配色**：奶油白 `#F1F0E7` 承担桌面，钴蓝 `#2348C5` 用于当前账号、主要操作与展开标题，橘红 `#CE4B26` 用于欢迎标签、进入工作台与需留意的提示。浅蓝是材质的陪衬，不使用蓝紫渐变或毛玻璃。
- **字体**：英文优先 Arial Rounded MT Bold，回退 Trebuchet MS；中文使用 Microsoft YaHei UI；ID 和版本使用 Cascadia Mono / Consolas。英文封面字约 95 px、中文页标题 39 px、正文 12–14 px、辅助信息 9–11 px。无外部字体请求。
- **形状**：圆角用于握持感和可按压的控件；名册仍是连续纸面结构，不把功能拆成重复卡片。按钮下沿 3–4 px 的实色阴影表达深度，不靠模糊光晕。
- **角色**：波比为原创生成的哑光软胶机器人，奶油白面板、橘色耳罩与靴子，材质和控件属于同一组颜色。它是示例角色卡，不是新增桌宠功能。
- **布局**：主页是一张开放的陈列台；配置页根据任务分别使用展开名册、能力抽屉和设置行。没有三列功能卡片或指标面板。

## 动效与状态

按钮按下移动 2–3 px，同时减小下沿阴影；开关的圆形拨片移动 21 px；角色装置随指针产生最多约 5 px 的水平位移和 3 px 的竖向位移。页面切换为 320 ms 的短暂轻移。系统减少动态效果时停用，设置页也能关闭角色跟随与页面进入动效。

QQ 连接、自动回复、角色绑定、模型是否配置分别表达，不使用一个「在线」替代全部状态。颜色均有文字配合。修改后离开页面、切换账号或展开其他编辑项时，提示继续编辑、放弃或保存。

测试按钮只发起示例反馈，测试中暂时禁用。搜索无结果有独立提示。原生 dialog 提供模态焦点约束和 Esc 关闭。

## 文档依据与功能边界

仅依据已有项目文档设计。来源沿用 [总体架构及产品规则清单](../sunny-correspondence/DESIGN.md)：01 总体架构、15 账号模型与会话角色修订、19 品牌、26 后端目标架构、46 世界书、61 记忆方案、79 扩展方案与开发文档导航。本轮未读取项目业务代码。

九个主页面均可访问：主页、总览、实例与监听、资料与角色、插件与 Skill、模型配置、事件诊断、资源库、应用设置。

- 模型按账号配置，对话、识图、视频识别、生图、语音生成分别选择。
- 每个群聊或好友显式绑定角色；展示头像和账号名字不决定运行人格。
- 世界书固定版本，资源库编辑不会自动改变绑定。
- 暂停自动回复不等于停止 QQ 监听。
- 公用资源共享定义，账号经历分别保留。
- 不恢复聊天历史或任务媒体页面，不增加记忆管理、跨账号管道、插件市场或浏览器任务。

「能力抽屉」只是配置的组织方式，「玩具」只是美术母题；没有引入养成数值、情绪系统或未经文档确认的新功能。

## 交付与限制

- `index.html`：多文件原型入口。
- `nowadays-soft-machines.html`：自包含的单文件离线稿。
- `design-board.jpg`：主页、角色与模型的三页总览。
- `style-comparison.jpg`：与「私人频段」的主页面并排对比。
- `preview-*.png`：浏览器实际渲染的九页截图。
- `tokens.css`：统一颜色、字体和动效变量。
- `bobi.png`、`ART-PROMPT.txt`：内置 ImageGen 生成的角色原画与最终提示词；无参考图，透明背景。
- `review.json`：布局与原型交互的检查记录。

全部数据均为虚构示例，刷新后重置。保存只用于本次演示，不会连接 QQ / SnowLuma、调用模型、读取聊天内容或保存真实密钥。导入只演示选择文件及预览位置，不解析或上传内容。

重点是三个核心页面的美术和交互方向，其余页面提供一致的界面语法。正式实现仍需补齐真实加载、请求失败、引用影响、版本冲突、资源正文编辑、付费测试确认和原生窗口行为。未改动现有前端与 EXE。

自评：概念 5、层级 4、细节 4、产品针对性 5、克制 4、结构差异 5。与另一套方向并列保留，供实际画面对比。
