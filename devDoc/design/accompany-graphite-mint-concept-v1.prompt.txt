Use case: ui-mockup.
Create a single premium, realistic, implementation-ready Windows desktop application UI design screenshot for "Accompany", a personal QQ AI companion manager. This is an actual product workspace mockup, NOT a marketing landing page or poster. Landscape image approximately 16:10, high resolution with crisp text. Front-on orthographic screen, no device frame, no perspective, no desk, no outer scene, no watermark. The application fills the canvas.

Design direction: minimalist graphite-black workspace, ice-mint/cyan accent, refined subtle depth, approachable personal companion identity. Use background #0B0D12, flat solid surfaces #131720 and #1B212D, light text #E8EDF5, secondary text #A4AFBF, primary accent #67E8D1 with almost-black button text. Tasteful single thin highlights, faint separation rather than excessive boxed cards. No purple, no magenta, no full-screen gradients, no cyberpunk HUD, no neon outlines around everything, no particles, no decorative dashboards/charts. Main content readable and calm, generous but practical spacing. Fluent-like crisp control proportions, small consistent line icons, 8px button radii, 12px panel radii, excellent Chinese sans-serif typography. Subtle frosted effect only on the right-hand floating details panel. Accent should occupy under 8 percent of the frame. Graphite flat planes must dominate. No giant marketing title.

"工作空间" group: "实例管理" (active with a restrained cyan-tinted selected pill), "会话", "任务".

Main content top slim summary text "2 个账号 · 1 个监听中 · 1 个已暂停" rather than three big metric cards.

The screenshot must feel like polished shipping desktop software with a personal warmth, not generic AI-generated dark admin cards. Static screenshot only: no motion arrows, no extraneous captions.
