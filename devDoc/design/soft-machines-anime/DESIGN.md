# SOFT MACHINES / ANIME EDITION

桌面玩具 · 二次元版 · 2026-10-27

## 本次基底

用户明确选择「桌面玩具」版的整体 UI 布局、展示和风格。本稿直接以该独立原型为基础，保留它的空间结构与控件，再加入用户认可的夏澄立绘。

保留：左侧角色、右侧账号与操作的开放式主页；顶部账号切换；底部 Dock；可展开的角色配对名册；五个能力抽屉；按钮的实色下沿、按压反馈和圆润排版。

调整：将波比玩具素材替换为夏澄二次元立绘；角色标签、资源名称和角色文案统一对应夏澄；钴蓝略向深蓝收敛，橘红改为珊瑚红，奶油白与浅蓝的层级沿用原版。

本稿不使用视觉小说场景铺底、姓名台词框或右侧书签导航；这次的二次元化发生在用户选定的桌面布局中。

## 三个核心页面

| 页面 | 沿用的结构 | 二次元表达 |
| --- | --- | --- |
| 主页 | 顶部账号切换，左侧视觉，右侧 HELLO AGAIN、账号名、签名与操作，底部角色关系摘要和 Dock。 | 左侧是夏澄独立立绘与姓名标签，保留浅蓝展示底面和轻量角色跟随。 |
| 资料与角色 | 可筛选的连续名册，选择目标后原位展开角色和世界书，右侧资源预览。 | 示例角色替换为夏澄；右侧明确标记为角色预览样本，不将它冒充其他角色的立绘。 |
| 模型配置 | 五类能力抽屉、当前能力的服务与模型选择、临时测试反馈、页头保存。 | 只统一配色和文案；不向模型配置中加入与任务无关的角色装饰。 |

调整了一个原型显示细节：未绑定角色标签恢复为紧凑行内状态，不让通用空态样式撑高名册行。

## 视觉参数

- 奶油白 `#F3F0E9`、阅读面 `#FFFCF7`，保留原版的明快桌面感。
- 钴蓝 `#344FBD` 继续承担品牌、选中状态与主要动作，珊瑚红 `#C3574B` 用于角色姓名标签与进入工作台。
- HELLO AGAIN、页标题、按钮、表单的字体与比例沿用桌面玩具；不引入楷体功能标题。
- 角色立绘从用户认可的二次元版直接复制，没有重新生成或改变人物。通过 CSS 排布为主页三分之四身展示与角色资源预览，文件本身保持不变。
- 保留原版的按钮下沿、圆形拨片、底部导航深度和短暂按压反馈；没有毛玻璃或渐变面板。

## 范围与依据

依据 [桌面玩具版设计说明](../soft-machines/DESIGN.md) 与其中列出的项目总体架构、账号模型、显式角色绑定、世界书及扩展文档。仍未读取项目业务代码；本次仅复制并调整此前生成的独立设计原型与素材，现有前端和 EXE 保持原样。

保留九个主页面以及原型交互。QQ 连接与自动回复分别控制；群聊和好友分别绑定角色；五类模型能力按账号选择；世界书固定版本；公用资源共享定义，不共享账号经历。

不增加聊天历史、任务媒体、记忆管理、好感度、抽卡或跨账号管道。夏澄是示例角色资源，主页的展示不设为整个账号的默认运行人格。

所有账号、号码、状态与内容都是示例。保存仅影响当前演示会话，刷新后复位。不连接 QQ 或 SnowLuma、不调用模型、不读取聊天消息、不保存真实密钥。导入只演示选择和预览位置。
