# UI 图稿复核与交付边界

日期：2026-10-22。图稿通过生图工具生成，不是功能验收证据。

## 统一标准

- 主页采用已确认的暖米白展示方案：图像、QQ 名称/号码、签名与 Dock；工作台保持清楚的导航与操作结构。
- 工作台与资源库延续暖米白、燕麦灰、琥珀强调色；不使用纯黑大底、不放账号展示 Dock。
- 正式实现的正文、表单、日志使用无衬线字体。部分生图中文字偏衬线或字形不稳定，不作为字体资产与可复制文案。
- 部分图稿主按钮仍生成了白字，正式实现统一为 Token 定义的深棕字，不能照抄白字琥珀底。
- 所有名称、账号、服务、统计均为假数据；生图上的状态不能当接口已经实现的证据。
- 具体后端能力与待补接口见 13，人工与自动化验收见 14。视觉图不能验证键盘、对比度、动效、异步账号隔离和 EXE 行为。

## 逐页要求与复核

| 页面 | 核对重点 | 交付说明 |
| --- | --- | --- |
| 01 主页 | 温暖留白、签名、账号 Dock | 沿用已认可图；悬停只放大，点击才切换展示，真实动效按文档实现 |
| 02 总览 | 账号/运行状态与任务分区 | 已修订原稿误写的视频生成，统一视频理解；不开放不存在的频道能力 |
| 03 实例 | 检测 QQ、由用户决定注入、监听与暂停 | 正式按钮写“注入并监听”；进程详情仅保留用户判断需要的兼容性和权限状态，不照搬内存读写等技术文案 |
| 04 资料 | 账号身份、展示图、角色卡分开 | 图中“在会话中向他人展示”文案不准确，应改为“用于本应用主页展示”；签名覆盖为本地草稿，上传接口待补，世界书/记忆为规划 |
| 05 扩展 | 公用来源、账号启用与私聊/群聊范围 | 图中已启用筛选下仍出现未安装项，正式实现该组合应过滤掉；安装、启用、策略和就绪分别展示，Skill 制品接口待补 |
| 06 模型 | 全局服务定义、地址/密钥、独立能力 | 账号绑定另配；测试要声明是否可能产生调用，不自动测试收费生图 |
| 07 策略 | 账号硬授权与群聊覆盖 | 图片生成与视频理解独立，具体会话不能越过账号授权 |
| 08 会话 | 发送账号与目标明确 | 人工发送仅在此；切换账号时不能显示或发送旧账号草稿 |
| 09 任务 | 视频理解、取消与未知结果 | 远端结果未知不可自动重提，取消不承诺远端已停止；缩略图不等于现有媒体浏览实现 |
| 10 诊断 | 温暖背景、筛选、脱敏详情 | 清空视图不等于删除审计；模型失败不等于 QQ 离线 |
| 11 设置 | 外观/Dock 动效与手动接入规则 | 重启仅恢复展示；正式实现默认遵循系统减少动效，放大范围按方案收敛，图中1.6倍非硬性指标；图中开关非现成功能 |
| 12 资源 | 公用定义、私有副本、版本引用 | 正式实现需补“Skill独立制品接口待补齐”提示；日常世界设定、作息提醒等仅示例，不能展示为已可用制品；共享不共享历史，世界书仍为规划 |

本交付覆盖各主页面默认状态。抽屉、空态、错误态、确认弹层、窄窗口与减少动效状态按 13/14 的组件和状态规范开发，不宣称本次已逐一生图。上线前仍需真实接口、真实 QQ 与打包 EXE 验收。
