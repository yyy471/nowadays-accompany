# 暖深灰 + 琥珀：视觉候选

使用内置 image_gen 新生成，已通过 view_image 复核。静态候选图，不是实际运行截图，不替代交互/动效或可访问性验收。未确认用户采用，未修改应用代码。

## 本次方向

- 以暖炭灰、烟褐灰、象牙白和低饱和琥珀构成层次，避开前两版冷色管理台气质。
- 实例采用平面列表、细分隔和小缩略图，减少卡片与圆头像。
- 右侧采用角色资料页形式，主体是角色名和简洁配置，气氛图缩为浅横幅。
- 主要强调“注入并监听”，暂停、恢复、停止为次级文字动作。

## 复核与保留意见

- 色彩与布局变化清楚，暖色和植物静物更接近安静的私人书房，模板卡片感降低。
- 主标题和角色名使用了展示宋体，个性更强；常用设置、消息和密集标签仍应采用清晰的 UI 无衬线字体。
- 该方向偏安静、人文，不直接体现此前希望的科技感和炫酷动效；若采用，动效可做细腻抽屉过渡、短琥珀光带与状态转换，避免常驻大面积运动。
- 图中主标题仍大于最终桌面建议；真实样板中收缩标题和右侧横幅，验证 125%/150% 缩放。
- 左下角把 SnowLuma 表现为用户名称，真实实现必须改为正确工作区/账号身份，运行时状态另列。
- “正在陪伴 02”包含一名已暂停账号，正式文案可用“我的实例 02”避免暗示两个都运行中。
- UI 中不使用占位图标暗示尚未验证的登录身份；用户 QQ 头像和角色头像明确区分。

仍需通过真实组件原型确认质感。暖配色本身不能解决全部模板感。
