# 夏澄的日常手账 / CHARACTER STUDIO

2026-10-27 · 保留桌面布局，重新设计角色、场景和控件的关系

## 设计回应

用户指出，上一版主要移动了角色，界面其他部分没有充分定制。本稿以用户选定的「桌面玩具」空间结构为基础，重新制作局部场景，编排主页，并另写角色配对与模型抽屉的呈现。

用户建议背景在角色身后局部出现，以水墨边缘控制范围；同时授权自行加入有意义的创意。本稿选择「角色手账」作为统一线索：沿用夏澄立绘，背景自然化入桌面，配色和按钮取自她的衣料与红色手账，便签只承担角色设定的摘录，不增加玩法。

## 本次的实际设计

### 1. 局部场景与角色

使用原社团室背景作为参考，通过内置 ImageGen 制作四周具有透明干笔边缘的新场景片段。中央保留窗光、樱树、书桌和手账，边缘是不规则笔触与细小透明空隙，不是圆角矩形或普通高斯模糊。

场景只在左侧角色展示区出现，留出右侧账号与操作的安静阅读空间。人物独立位于前景；场景与人物有不同方向的几像素跟随，减少动态效果时关闭。原始角色文件直接复制，没有重新生成面部。

主页增加一张带折角的角色便签，摘录夏澄的设定。它不是实时对话，也不会发送到 QQ。姓名索引、手账便签与按钮的下沿属于同一组纸面与书脊语法。

### 2. 从角色提取组件配色

| 来源 | 色值 | 具体用途 |
| --- | --- | --- |
| 深蓝发色与长裙 | `#394158` | 品牌、导航当前项、账号切换、开关和保存操作。 |
| 樱粉开衫 | `#D9B2BC` | 姓名标签细线、便签上缘、选中区域的浅色关系。 |
| 手账红 | `#914E5A` | 进入工作台、测试按钮、作用范围与关键链接。 |
| 奶油纸面 | `#F5F0E8`、`#FFFCF7` | 桌面与编辑面，保持原版留白。 |
| 可读辅助文字 | `#6D6574` | 说明与参数；在浅粉面上约 4.71:1 对比度。 |

主要按钮采用手账红表面、较深下沿和独立的箭头端片。保存按钮使用深蓝，次要动作保留轻量文字。开关、账号切换、筛选、输入与测试结果同步遵守这组颜色，不沿用原钴蓝主题。

### 3. 角色配对重新组织

总体仍是左侧名册、右侧角色资源。展开区新增清楚的当前修改对象，角色与世界书字段按同一栅格对齐，说明与保存动作分开，版本与未保存状态保持可见。

右侧角色预览复用局部场景与立绘，附上设定、版本和资源入口。它明确是夏澄的资源样本，不会因选择另一张角色卡就冒充对应的立绘。

### 4. 模型能力抽屉重新设计

保留五个能力抽屉这一操作方式。展开标题使用浅粉背景和深色文字，编号、开关、选择框、测试卡片与按钮另行设计。左侧负责配置，右侧负责本次测试；配置与结果在视觉上分区。

保存不调用模型。测试中显示等待状态、禁用本次触发按钮并设置 aria-busy；完成后恢复并保留独立结果样式。图片和视频选择各自测试文件；未配置的能力不影响其他能力。

## 交互与校验

保留草稿离开提示、放弃恢复、账号切换、搜索筛选、配对保存、能力展开与示例测试。按压下沿减小、焦点立即出现，尊重系统减少动态效果和应用动效开关。

关键配色样本的 WCAG 对比度：深蓝按钮与纸白文字约 9.91:1，手账红与纸白约 5.96:1，展开标题墨色与浅粉约 9.86:1。状态同时使用文字，颜色不是唯一信号。

## 架构边界

沿用 [桌面玩具版文档依据](../soft-machines/DESIGN.md) 中的总体架构、账号模型、逐目标角色绑定、世界书、记忆与扩展文档。仅处理独立设计稿、原创素材和原型，不读取项目业务代码，不改动现有前端或 EXE。

九页入口均保留。模型五类能力按账号选择，群聊与好友显式绑定角色，世界书固定版本；公用资源只共享定义。暂停自动回复和停止 QQ 监听分别控制。

不引入聊天历史、任务媒体、记忆管理、好感度、抽卡、跨账号管道或未确认的游戏功能。所有人物、账号、号码、版本和状态均为示例；保存只作用于演示会话，刷新复位。原型不连接 QQ / SnowLuma，不调用模型、不读取消息、不保存真实密钥。导入只演示选择和预览位置。
