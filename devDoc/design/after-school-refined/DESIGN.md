# 放课后通信 / UI 精修

2026-10-27 · 保留原画，打磨界面

## 本次目标

用户认可上一版的角色与场景，指出 UI 的精致感不如「桌面玩具」。本稿保留两张原画，借用该版清楚的功能字体、实体按钮反馈和表单层次，统一打磨现有九页原型。

没有重新生成、重绘、裁改原画；角色与场景文件从上一版直接复制。没有读取项目业务代码或改动现有前端、EXE。上一版独立设计稿也保留。

## 具体调整

| 部分 | 精修处理 |
| --- | --- |
| 功能字体 | 页标题、表单、台词与操作改用统一无衬线。楷体不再承担功能标题和长说明；保留场景本身的叙事气氛。 |
| 字级 | 页面标题约 29 px，主操作 12–13 px，表单 12 px，说明 10–11 px；减少过小的正文与过长的英文标签。 |
| 导航 | 右侧书签收成完整导航条；统一图标尺寸与按钮间距；选中项采用清楚的靛蓝实色。移动端仍是五个固定入口。 |
| 主页操作 | 收敛为进入工作台、查看角色档案两个直接入口；模型仍由常驻导航访问。按钮统一高度、圆角和按压深度。 |
| 台词框 | 移除重复内外细边框，使用一层清楚的阅读面；姓名条、换一句与说明形成稳定层级。台词依旧是预设展示，不发起模型请求。 |
| 角色页 | 目标目录、角色海报、绑定编辑形成各自明确的区域；搜索、筛选、状态标签和保存动作遵守同一尺寸节奏。 |
| 模型页 | 能力目录与当前设定区分层；输入框、按钮统一高度和圆角；测试反馈有独立区域与成功状态。 |
| 状态栏 | QQ 连接与自动回复分别用文字和状态点表达，收在固定位置。 |
| 交互反馈 | 鼠标悬停改变背景；按钮按下时移动并减小下沿；焦点立即出现；测试与草稿保护保留。 |

## 视觉参数

- 应用底色 `#F0F1F7`，阅读面 `#FFFEFB`，文字 `#283149`。
- 操作色 `#5966AD`，浅选中面 `#EDF0FB`，保留少量樱粉 `#EBC1CD` 呼应角色服装。
- 导航外壳 20 px、编辑区域 15–17 px、按钮与输入 9 px；圆角按对象层级区分，不对每个小元素重复画面板。
- 输入框约 43 px，主要操作约 42–46 px。边框宽度在默认、焦点和填写状态保持不变。
- 轻阴影用于区分前后层级，明确的按钮下沿用于按压反馈；没有毛玻璃或渐变面板。
- 场景、角色层、原型路由与业务边界沿用原稿。

`refinement.css` 集中保存精修规则；`refinement.js` 只调整独立原型的导航图标、文字层级及主页操作数量，不访问实际应用。

## 产品边界

沿用 [原方向稿的架构依据](../after-school-letters/DESIGN.md)：九个页面、逐目标显式角色绑定、按账号选择五类模型能力、固定世界书版本、QQ 监听与自动回复分开、公用资源共享定义而经历各自保留。

不增加聊天历史、任务媒体、记忆管理、抽卡、好感度或跨账号管道。所有账号、号码与状态均为示例；保存仅作用于当前演示会话，不连接 QQ / SnowLuma，不调用模型或保存真实密钥。
