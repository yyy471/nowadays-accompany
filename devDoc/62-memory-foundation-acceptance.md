# 长期记忆基础验收标准

日期：2026-10-26。状态：MEM01管理存储已执行，S01～S12在[65 修复R1～R3](65-memory-management-review-fixes.md)后通过；C01～C11、T01～T09、U01～U08待执行。对应[61 实现方案](61-memory-foundation-implementation-plan.md)，继承54号M01～M14及全阶段交付约束。本文件细化到可派发任务，不预填通过。

## 1. 环境与原则

测试scope：账号A/B、A私聊P与群聊P、同会话角色R1/R2、同角色切世界书W1/W2；准备手工fact、summary来源区间、待处理提取、错误/超限模型返回。

自动测试使用独立临时dataRoot、FakeChannel/FakeProvider、有界并发门控和可注入文件错误；不调用真实服务或QQ。不得依赖Windows必定能创建链接或设置chmod，不允许新增skip掩盖相关行为。

P0：隔离/越权/丢数据/错误删除/陈旧写入与回复。P1：主链路/预算/恢复。两级全部通过才能放行；界面妨碍正常操作同样阻塞。暂未实现的后续包只能标待执行，不能将整个阶段提前宣布通过。

## 4. MEM03 自动提取与摘要

| ID | 级别 | 场景 | 预期 |
| --- | --- | --- | --- |
| T01 | P0 | 仅enabled或仅autoExtract开启 | 不提取；只有两个都明确启用才执行 |
| T02 | P1 | 超时、队列满、单scope慢/跨scope任务 | 有界拒绝/取消，不阻塞普通对话或无限堆积 |
| T03 | P0 | 提取期间关开关/删记录/清空/换角色/退出 | generation/epoch失效不写结果，旧回调和重启不复活 |
| T04 | P1 | 非JSON、未知字段、超大/太多记录、伪造source | 严格拒绝或明确安全跳过，不执行模型指令 |
| T05 | P0 | 相同来源范围重复提交/回调/失败重试 | 不重复记录，失败不推进成功水位，提交记录与水位原子一致 |
| T06 | P0 | 手工编辑与模型建议冲突 | 不静默覆盖用户内容，落盘前重验state revision/generation |
| T07 | P1 | summary选中/未命中/超预算/删除 | 仅实际选中且范围有效时省略对应原历史；其他情况保留原历史 |
| T08 | P1 | 模型/网络失败、成本未知或重启 | 明确状态，不自动重发付费请求，不将失败摘要写成事实 |
| T09 | P1 | 用户删除后未来再出现相同事实 | 根据实现前定稿的抑制策略验证并显示；不能把一次generation变化宣传为永久遗忘 |

先以Fake模型完成以上故障/隔离验证；真实服务测试按当次用户授权和测试账号进行。若先只发布fact提取，summary相关验收标待执行且UI不暴露未完成summary功能。
