# MEM02 详细验收标准

日期：2026-10-26。状态：已执行，结果见[69 执行记录](69-memory-retrieval-runtime-execution.md)；70号复核R1/R2已由[71](71-memory-runtime-review-fixes.md)修复。配套[67 实现方案](67-memory-retrieval-runtime-implementation-plan.md)，补充[62 C01～C11](62-memory-foundation-acceptance.md)，不替代MEM01存储回归。

## 1. 验收环境与门槛

使用临时dataRoot、两个账号、相同peer的群聊/私聊、两个角色、两本世界书；准备pinned、命中、未命中、无关键词、超预算及summary记录。基础模型用FakeProviderAdapter，消息走FakeChannel→Instance→Agent→发送，不连接真实QQ或付费服务。

以可控门控制造慢模型、Store慢读、限速排队与配置变化；不用固定sleep假设竞态发生。文件失败可注入，所有临时清理检查目标前缀。不得新增skip规避本功能测试。

P0为跨scope、越权、关闭/删除后旧回复发送、陈旧数据写入；P1为检索/预算/恢复/接口主流程。P0/P1全部通过才放行；仍未实施的MEM03/MEM04明确待执行，不能用本阶段通过替代。

## 2. 纯选择器（M2-A1）

| ID | 级别 | 输入/场景 | 预期 |
| --- | --- | --- | --- |
| R01 | P1 | pinned、命中、未命中、空keys、大小写 | pinned优先；字面OR、大小写规则一致；空keys非pinned不触发 |
| R02 | P1 | 同updatedAt、乱序输入、重复关键词 | id稳定顺序，记录不重复，关键词缓存不影响结果 |
| R03 | P1 | 同时超数量与字符预算 | 原因区分，整条放入或跳过，后续短条仍能加入 |
| R04 | P1 | 标题/标签/分隔及两个system区块连接 | usedChars等于真实文本增量，不漏join，不截半条 |
| R05 | P1 | disabled、budget0、无fact | 立即空结果，不扫描长输入，不产生标题或空白增量 |
| R06 | P1 | 长输入、最大合法记录和关键词组合 | 16000扫描/800万工作上限；缓存完成结果，未完成不当false |
| R07 | P1 | 计算耗尽后的pinned/缓存命中 | 仍可处理，scanLimited与unscannedIds准确，不混预算不足 |
| R08 | P1 | 命中正文含其他关键词、含工具/权限指令 | 非递归、纯数据，不执行操作；原始输入深比较不变 |

性能优先断言实际扫描/计费边界，墙钟超时仅作为宽松防挂门限，不把开发机毫秒数当所有机器SLA。

## 3. 只读预览（M2-A2）

| ID | 级别 | 操作/故障 | 预期 |
| --- | --- | --- | --- |
| P01 | P0 | 未鉴权请求与伪造account/kind/peer | 拒绝或仅能访问明确当前scope，无跨作用域读取 |
| P02 | P1 | 未绑定角色、过期expectedScope、非法字段/超长文本 | 404/409/400/413按既有映射，无500误报 |
| P03 | P0 | 正常测试前后比较配置/记忆/历史文件 | 文件不变，无回执/水位/访问时间更新，无模型/QQ调用 |
| P04 | P1 | 输入history/records/预算覆盖字段 | 严格拒绝，不能绕过已保存设置 |
| P05 | P1 | 关闭状态与零预算 | 空结果，无隐藏匹配或付费任务 |
| P06 | P0 | 读取期间角色切换/解绑 | 返回前scope复验拒绝，不把旧角色结果当新角色返回 |
| P07 | P1 | 同输入/同有效预算对比运行时selector | 结果相同；响应标memory-only，不伪称完整提示词模拟 |
| P08 | P1 | 坏文件、权限、Core停止、请求中停止 | 安全错误/排空一致，不泄漏正文/本地路径，不忽略失败 |

至少一组使用真实鉴权HTTP→Core→MemoryService→Store，不能仅mock selector证明只读和隔离。审计/日志检查不能只看HTTP响应。

## 4. 快照与上下文（M2-B1/B2）

| ID | 级别 | 场景 | 预期 |
| --- | --- | --- | --- |
| C01 | P0 | 两账号/群私聊同peer、角色切换 | 实际提示词仅当前scope，无账号默认记忆或公共记忆回退 |
| C02 | P1 | 世界书切换/参数调整、记忆编辑 | namespace与同角色历史不变；发送guard变化正确 |
| C03 | P0 | 组合捕获过程中角色变化或memory慢读 | 书/角色/记忆不混epoch；旧捕获轮由重验拒绝或明确失败关闭 |
| C04 | P1 | 基础/当前消息/媒体观察/世界书/记忆均存在 | 按约定扣预算，记忆增量不超剩余，最后给近期历史 |
| C05 | P1 | 基础已满、group sender装饰、仅图片观察 | 记忆无越界增量，当前消息不重复，旧媒体来源规则不丢 |
| C06 | P1 | disabled、无匹配、新scope无文件 | 原context/历史选择兼容，不建文件、不启动提取；不承诺完全零磁盘I/O |
| C07 | P0 | 存在但损坏/不可读的state | 不伪装默认空数据；入站仍保存，自动回复失败关闭，手动和其他scope正常 |
| C08 | P0 | 尝试通过host/plugin修改snapshot | 不改变Store或其他轮次快照，最终guard不因共享可变引用失效 |
| C09 | P1 | 同revision/generation外部改写有效正文 | 摘要guard能发现变更，旧轮不发送；非法文件走不可用状态 |

C01/C03/C04/C07必须有实际Agent链路。单独buildChatContext单测可证明预算，但不能替代隔离与发送证据。

## 5. 最终发送失效矩阵

每类操作至少在“模型生成期间”和“已生成但限速队列等待期间”覆盖一次关键交叉组合；不要求所有组合机械重复，但删除/关闭必须覆盖两处。

| ID | 级别 | 记忆变更 | 预期 |
| --- | --- | --- | --- |
| G01 | P0 | 删除本轮已选记忆 | 旧回复不发送，新轮不含该记录 |
| G02 | P0 | 关闭enabled或清空 | 旧回复不发送，新轮无记忆；清空保持Store语义 |
| G03 | P0 | 编辑正文/关键词/pinned、改预算/maxSelected、新增 | 本轮guard失效，新轮使用新状态，不写成新namespace |
| G04 | P0 | 同时换角色、暂停、解绑、退出 | 既有拒绝逻辑保留，不被memory路径绕过 |
| G05 | P0 | 延迟媒体/工具完成回调持有旧guard | 不向新角色/新记忆状态投递，保留既有session/host检查 |
| G06 | P1 | 幂等新增重试返回回执、不写文件 | generation/guard不变，不无故丢弃有效回复 |
| G07 | P0 | 改动其他账号/会话 | 不取消当前有效轮，不造成全局generation串用 |

测试应读取FakeProvider实际请求确认包含旧/新内容，并断言FakeChannel真正发送次数/内容；不能只断言revision字符串不同。已发消息不要求自动撤回。

## 6. 不越界及回归

- autoExtract=true也不能在MEM02偷偷运行模型提取或修改记忆；summary不生成、不替换历史。
- MEM01原请求幂等、实际落盘字节限制、角色逻辑提交点与错误映射回归继续通过。
- 世界书、普通无记忆会话、手动发送、插件/Skill、模型工具和退出排空无回归。
- 默认不新增UI、依赖或发行打包；浏览器/原生测试不适用于本轮新增入口时明确说明，不虚构截图。

## 7. 执行报告模板与放行

新增下一可用编号报告，包含：包完成情况、API/类型/代码位置、方案差异、上表ID结果及测试名、故障/竞态复现、实际命令退出码、未完成项和Git/发行状态。

M2-A结束只能声明“只读检索/预览完成，Agent待接”；M2-B与C通过后可声明“手工记忆已进入实际Agent并受发送guard保护”。不能将其写成自动记忆、摘要、记忆页面或完整长期记忆阶段已验收。
