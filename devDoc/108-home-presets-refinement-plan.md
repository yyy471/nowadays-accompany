# 首页精简与昼夜预置主题方案

日期：2026-10-27。用户依据真实窗口截图要求精简首页、禁止首页上下滚动，并将顶部账号栏替换为「白昼来信 / 晚风电台」。用户已选择晚风方向：同一位夏澄、夜间窗景与暖灯。

## 1. 本批范围

删除截图红框对应展示：顶部主页账号标签与全部账号图标、顶部全部菜单、今日桌面/账号条、QQ连接徽标、安排角色、自动回复面板、插画运行角色说明、角色绑定摘要。保留品牌、设置按钮、右侧账号资料、主入口、局部场景与便签、底部导航和运行信息。

顶部是外观切换而非QQ账号切换；本地记住选择，不发业务请求，不写账号配置。不同业务页仍通过自己的账号控件选择对象。首页不再读取账号policy或角色绑定，也不产生Agent写操作。

## 2. 两套预置

| | 白昼来信 | 晚风电台 |
| --- | --- | --- |
| 气质 | 当前奶油手账、阳光窗景 | 同一房间的夜间窗景、暖台灯 |
| 底色 | 奶油纸面 #F5F0E8 | 墨蓝 #171D29 |
| 文字 | 深蓝 #30384D | 暖白 #EEE5D8 |
| 主动作 | 手账红 #914E5A | 琥珀 #D4AA87，深色文字 |
| 辅助强调 | 樱粉 | 低饱和玫瑰灰 |
| 素材 | 保留原透明场景与立绘 | 基于原透明场景重绘夜晚；沿用同一立绘，适度降低曝光与饱和度 |

夜景使用imagegen内置工具编辑原图，保持窗格、桌面、樱花、透视和透明干笔边缘；不把整张页面生成成图。应用仍以真实React组件渲染。

## 3. 布局与状态

首页改为固定可用高度内的插画/文字双栏，窄屏改成图文分区。优先减少空隙和调整插画占用，再切换紧凑布局；不靠全页缩放或把操作藏在裁切范围外。长签名限制展示行数并提供完整title，其他页面仍可正常滚动，菜单和弹窗仍可内部滚动。

同一套primitive→semantic→component token支持两种预置；夜间override经过同一生成器校验，嵌套scope和Portal同步携带预置。切主题不卸载业务编辑器，不导航、不丢弃草稿。未迁移业务页只映射原有调色变量，保留布局与控件规格。

## 4. 验证与交付

验证截图中的删减项、两主题一屏布局、主题记忆、不改变QQ身份/不产生业务写入、全部菜单、主题下草稿和确认框、坏图/长文本/减少动效，以及隔离原生Electron缩放。运行类型检查、全量Vitest、桌面构建与组件样板复核。
