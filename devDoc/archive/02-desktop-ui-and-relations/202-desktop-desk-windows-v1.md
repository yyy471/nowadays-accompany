# Nowadays 书桌 Windows 前端初版

本轮将 [201 的离线书桌样机](201-desktop-desk-preview-record.md) 接入独立的 Windows 应用。书桌和对话遵循 DL-131。前端源码位于 [desktop/desk-preview](../../../desktop/desk-preview)，入口是 [Electron 主进程](../../../desktop/desk-preview/main.cjs)。

## 使用

便携版为 `Nowadays-Desk-0.1.0-win-x64.exe`。打开后进入独立桌面窗口。关闭窗口后保留托盘，从托盘可重新打开书桌或明确退出。

| 物件 | 操作 |
| --- | --- |
| 主拍立得、便笺 | 进入当前角色的独立对话。返回时照片收回，键盘焦点回到原入口。 |
| 挂历下的照片 | 切换角色，保留各自的会话草稿与本次会话内容。 |
| 台灯 | 开关真实预渲染的台灯照明与局部补光。按 `N` 也可切换。 |
| 挂历 | 打开环境面板。时间、天气、季节与台灯各自可预览或恢复自动。 |
| 玩偶 | 点击轻弹。阿柚缺少玩偶素材时由当前角色样例隐藏这一层。 |
| 六本书 | 书脊悬停轻抽，点击打开她的一天、相册、角色卡、模型、技能与连接、设置。底栏书架入口提供同一组操作。 |

## 环境与素材

- 使用既有 Blender 小院的模型、机位与材质。运行资产包含清晨、白昼、黄昏、夜间、阴天、雨天、湿冷夜景，每组各有台灯开和关的两张底图。时间按本地时钟驱动，晨昏在关键帧之间渐变，季节改变晨昏区间。
- 日期驱动四季，窗内有春瓣、夏季绿意、秋叶、冬季冷色和杯口热气。晴、阴、雨、雪可手动切换。自动天气是按日期和季节变化的离线场景模拟，设置保存在应用配置中。
- 使用 Electron 39.8.10 和 electron-builder 26.15.3，Windows x64 便携目标。本机实现方用已有的 Electron 运行时和 NSIS 缓存打包。该包供本地前端体验，未做发行签名。对话、日常、模型与技能内容使用离线示例或接入说明。真实会话、模型绑定与远程 MCP 沿 [200](200-desktop-frontend-development-plan.md) 和 DL-115 的排期。

## 开发与复核

在 `desktop/desk-preview` 下安装该目录声明的开发依赖，再运行：

```powershell
npm install
npm start
npm run package:win
```

打包产物位于该目录的 `dist`。Blender 源仍用小院版，日常更新素材用 [渲染脚本](../../../desktop/desk-preview/tools/render_desk.py) 和 [资源打包脚本](../../../desktop/desk-preview/tools/package_assets.py)。

本轮实现方验证覆盖便携 EXE 启动与进入对话、打包窗口的六本书入口、玩偶动作、角色和草稿隔离、中文输入、开关灯、季节天气切换、减少动态效果、关闭到托盘与环境设置重启恢复。正式桌面发行与真实后端接入继续按对应工作包验收。
