## 2. 总体画面布局架构

### 2.1 纵向深度结构（Z 轴 5 层全屏穿透）

1. **Layer 1 · 远景天光与四季画室舞台层（Stage Backdrop）**
   - 基于高精度手绘水彩画室（`scene-ink.png` / `scene-night.png`）与庭院雪景／晴景图层，叠加随时间（清晨紫雾、晴昼暖金、黄昏琥珀、夜幕深靛）平滑插值的环境色温场与远景流动云层。
2. **Layer 2 · 窗畔角色与多姿态在场层（Living Character Layer）**
   - 5 层鼠标与呼吸视差（Multi-Plane Parallax）驱动角色高清原画（白昼捧书态 `character.png`、夜阑／专注阅读态 `character-night.png`、阿柚茶歇态 `photo-ayou.webp`）。
   - 配合 SVG/CSS 动态边缘光（Rim-Light）与台灯径向暖光染色，使角色发丝与肩头实时响应窗外日照角度与台灯开关。
3. **Layer 3 · 器物剧场工作台层（Tactile Medium Theater）**
   - 在「器物展开态」下占据右侧 `62%~65%` 黄金画幅（左侧 `35%~38%` 保留景深虚化的窗畔角色伴随舞台與实时行动脉搏卡）。
   - 承载四大器物介质：**折信长卷（对话）**、**双页皮质手账（日记与心境）**、**暗房拍立得长廊（记忆与证据）**、**黄铜怀表与方格手稿（她的一天与工作空间）**。
4. **Layer 4 · 全局大气粒子与光学投影层（Global Light & Weather Cast）**
   - 全屏 Canvas 2D 物理粒子引擎 + 光学混合层（`pointer-events: none`，穿透投射在角色与展开的纸页之上）：
     - **晴／昼**：斜射入室的丁达尔体积光束（God Rays）、随微风在纸面上轻轻摇晃的窗外树叶投影（Gobo Shadow）、空气中逆光漂浮的金色微尘；
     - **四季**：春樱花瓣（带三维翻转与前景大光圈虚化）、夏夜流萤与翠叶、秋日红枫、冬日六角结晶雪片与杯口袅袅升腾的流体热气；
     - **雨／阴**：双层景深雨丝、窗玻璃表面滑落并带高光折射的水滴轨迹。
5. **Layer 5 · 轻盈器物导航与折信工坊层（Whisper HUD & Atelier Drawer）**
   - **顶部悬浮两角**：左上「时节与环境怀表胶囊」（点开展开玻璃环境调音台），右上「微缩拍立得角色叠卡 + 台灯拉绳开关 + 折信工坊入口」。
   - **底部在场器物坞（Presence Dock）**：主舞台态下悬浮于桌沿，展示角色实时行动脉冲与四大器物快捷入口；支持直接按键打字自动推近镜头并展开对话信笺。

### 2.2 响应式与窗口适配

- **宽屏桌面（`>= 900px`）**：主舞台满幅画卷 ↔ 展开态「左 36% 窗畔伴随 + 右 64% 器物剧场」。
- **窄窗／侧边栏伴读模式（`< 900px`）**：严禁 `object-fit: fill` 非等比拉伸；自动平滑叠合为「上方 28% 窗畔动态取景横幅 + 下方 72% 器物介质区」。

## 3. 四大创意介质转场与功能设计

### 3.1 ✒️ 信笺 · 对话与主动分享（Letter Unfold）
- **转场动效**：镜头向左侧角色平滑推近（Focus Pull），右侧信笺沿折线呈 **3D 折纸展开（Origami Unfold）**，透出细腻棉浆纸纹与折痕高光。
- **核心交互**：
  - **主动分享折信卡**：顶部挂载带火漆印章与折痕的「她想对你说」信封卡，点击可展开并定位至分享上下文。
  - **多会话窗口切换**：信笺右上角提供轻量「书信夹页」切换同一角色的不同独立对话窗口（遵循共享长期记忆、独立窗口历史）。
  - **纸墨流式对话**：角色回复带羽毛笔书写流式渐显与中断标记保留；用户输入框按 DL-80～DL-82 处理中文 IME 组词、打字时左侧角色浮现「正在倾听」微光反馈、停输 1 秒状态同步。

### 3.2 📖 手账 · 日记与心境成长（Tactile Journal Flip）
- **转场动效**：皮质封面的双页手账本从桌面微旋升起并立体翻开，书脊处呈现真实的深邃弯曲阴影与丝带书签。
- **核心交互**：
  - **左页 · 此刻心境与近况（DL-25 / DL-48）**：手绘印章风展示当前心情（Mood）、近期关注点、状态更新时间与角色性格底色摘录。
  - **右页 · 亲笔日记正文（DL-26～28 / GAP-06）**：使用手写体（`hand.woff`）与衬线体混排展示 Markdown 日记，底部显示关联的来源经历事件标签；支持点击书角或右侧彩色材质索引贴触发 **3D 翻页动画（Page Turn）** 切换不同日期的日记。

### 3.3 🎞️ 胶片 · 经历记忆与证据回溯（Chronicle Filmstrip）
- **转场动效**：环境光柔和聚焦如暗房工作台，带有齿孔编号的胶片时间轴与拍立得记忆卡错落滑入。
- **核心交互**：
  - **多维检索与筛选（DL-17 / DL-93）**：支持按关键词、记忆类型（独立经历事件 `Event` / 日常摘要 `Summary`）、情绪色签与时间范围实时过滤，展示召回频次与精炼状态。
  - **抽拉式原始证据追溯（DL-16 / DL-92）**：点击任意拍立得记忆卡，卡片平滑左移并抬起，**从卡片夹层向右抽出一张带有打字机时间戳的「原始对话／活动证据便签条」**，直观核验记忆诞生的原始上下文。

### 3.4 🧭 推演 · 她的一天与工作空间（Co-Working Desk Spread）
- **转场动效**：斜俯视推演桌垫展开，左侧旋入黄铜刻度怀表盘，右侧摊开带方格底纹与回形针的活页笔记手稿。
- **核心交互**：
  - **自主活动与唤醒日程盘（DL-104～112 / GAP-01～02）**：可视化展示每日自主活动额度环（默认 200 点／可切无限制）、今日已完成与正在执行的自主任务链、下一次定时唤醒安排；支持现场触发「模拟角色自主行动（阅读／写日记／检索／分享）」以观察全屏在场状态联动。
  - **工作空间 Markdown 笔记手稿（DL-14 / DL-44）**：直接翻阅角色在工作空间沉淀的阅读笔记与任务成果，带荧光笔重点高亮与来源链接。

### 3.5 ✉️ 折信工坊 · 模型、Skill/MCP 与环境配置（Atelier Drawer）
- 点击右上角品牌折信徽标，从右侧滑出**深色蓝图与拉丝黄铜质感**的工坊抽屉：
  - **模型服务配置（DL-118～120 / DL-124）**：支持 OpenAI Chat Completions、Responses 与 Anthropic Messages 协议选择，提供「获取模型列表」下拉与手填模型 ID、「测试连接（独立简短请求，返回耗时与结果）」以及角色对话／记忆整理模型绑定。
  - **能力扩展开关（DL-35～36 / DL-59 / DL-71）**：内置本地 MCP 基础工具（文件读写、目录检索、脚本执行）与通用 Agent Skills 开关，明确展示“关闭立即阻止新任务、在途原任务链延续至结束”的状态说明。
  - **自主活动预算配置（DL-107）**：调节每日点数上限（如 200 点）或切换为「无限制」模式。

### 7.2 三轮 Electron 实机渲染审视与迭代优化

通过 Electron 实机加载 `desk://bundle/index.html` 对 8 组核心状态（秋日晴窗、春夜听雨开灯、黄昏书信交谈、春日双页手账、夏夜暗房胶片与证据单、冬雪怀表与手稿、阿柚角色切换与折信工坊、840×680 窄窗响应）进行了三轮截图审视与迭代打磨：

1. **第一轮审视发现与修复**：
   - *发现问题*：夜阑模式下继承自 `body` 的文字颜色未随 `.luminary-app[data-night="true"]` 切换，导致暗色毛玻璃胶囊与胶片面板上的部分标题偏暗；`theater` 焦点下拉周期过渡未在首屏同步结算，导致左侧角色与右侧剧场出现局部交叠；任务链列表项在 Grid 容器内被纵向拉伸。
   - *修复措施*：将 `color: var(--ink-primary)` 直接声明在 `.luminary-app` 根节点并补齐夜间 `--crimson`／`--jade` 变量；收敛左侧 34.5% 陪伴焦点区的角色与耳语气泡定位；为 `.task-chain-list` 补充 `align-content: start`。
2. **第二轮审视发现与修复**：
   - *发现问题*：使用 `requestAnimationFrame` 移除首屏 `.is-booting` 加上包含 `0% { opacity: 0 }` 的面板入场 `@keyframes`，在隐藏窗口或快速切换时易出现首帧闪烁；秋日窗外枝叶的色相偏移角度（`-26deg`）仍偏粉红；窄窗（`840×680`）下角色立绘上下边缘紧贴顶部胶囊与书签栏。
   - *修复措施*：改为同步 `void app.offsetHeight` 刷新布局后立即移除 `.is-booting`；将四大器物与证据抽屉的 3D 展开动画改为 `.is-entering` 仅在交互切换时触发且保持 `opacity: 1` 的纯 3D 几何变换；将秋日窗外树冠滤镜调校为 `hue-rotate(38deg) saturate(1.58)`，使窗外树冠随四季呈现「春樱粉 → 夏木翠 → 秋枫金 → 冬雪霜白」的自然流转；为窄窗顶部陪伴条增加圆角裁切与间距约束。
3. **第三轮审视发现与精修收口**：
   - *发现问题*：8 组场景全部清晰呈现、零控制台与页面报错，仅第四器物「自主日程怀表」中心区域的下次唤醒小字略微贴近内圈刻度环。
   - *修复措施*：将 `.brass-dial-wrap` 尺寸微扩至 `168×168px` 并收敛 `.dial-center-readout em` 行宽与字号，使怀表内圈读数留白舒展。
