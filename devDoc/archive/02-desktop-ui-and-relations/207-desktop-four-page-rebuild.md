## 实现范围

- 使用 `dev` 的白昼／晚风人物和场景素材，按原版主页与关系手账重新实现页面。
- 主页读取当前角色与状态；关系手账可读取角色、切换角色、创建角色和按版本修改名称与设定。关系页映射新角色模型，旧 QQ 账号、会话、插件权限等页面语义没有迁入。

- Electron 启动现有本地后端，同源转发 API；新入口取消原来的模拟模型和自动写入演示角色。

## 原版动效与布局补修

首轮自行重绘页面遗漏了 `dev` 已有的布局、交互与动效。现迁入该分支的 React 公共 UI、主页场景、手账 Dock、主题切换及关系手账样式和转场控制器；关系页使用新后端的角色与能力绑定数据。旧 QQ 会话和插件授权模型不属于新后端，本轮按角色模型适配，相关旧业务行为没有直接迁入。

渲染器独立依赖及构建位于 `desktop/desk-preview/renderer`。首次运行先在该目录执行 `npm ci`，然后在 `desktop/desk-preview` 执行 `npm start`。后端依赖仍按 `backend/README.md` 独立安装。

本机 Electron 隔离数据自验确认主页昼夜切换触发原版主题过渡，关系页昼夜切换触发手账专属转场，两个真实角色切换时依次出现收书和开书状态，Dock 和更多菜单可用。角色创建、设定修改、总览、透光状态及能力卡从后端读取也已验证。源码模式构建与类型检查通过。页面适配自验性质保留，独立复核及打包交付待后续验证。
