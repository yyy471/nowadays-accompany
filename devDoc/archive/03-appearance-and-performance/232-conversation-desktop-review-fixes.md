# 232 桌面对话页 231 复核修复记录

2026-11-09。针对 [231 桌面对话页独立复核](231-conversation-desktop-independent-review.md) FE-R01～FE-R04 的实现方修复与离线自验。下述结果不是独立复验结论。

## 修复

| 编号 | 修改 |
| --- | --- |
| FE-R01 | 增量句段仍按 ID 合并；终态全量列表替换临时列表，保留已阅读位置并限制在正式句段数内，更新当前演出句段。正式列表为空或更短、多出后续句段时也按同一规则处理。 |
| FE-R02 | 待播放音频与当前音频分开管理，只有收到新音频的 `playing` 事件才暂停上一句；合成、播放失败不影响上一句。切换页面／窗口或取消待播时释放候选音频，迟到的播放事件不能接管。 |
| FE-R03 | 对话栏的任务状态与查看入口按消息及起始句段绑定，每个任务只显示一次。已完成轮次找不到起始锚点时，独立显示未定位入口，不伪装成其他句段的任务；历史卡片也按起始句段匹配。 |
| FE-R04 | 实时演出退出跟随或进入历史时冻结当时的场景；历史定位保留舞台，显式查看旧图可覆盖冻结图，返回最新后重新跟随实时句段。切换角色或窗口清理冻结状态。 |

## 实现方自验

- 渲染器类型检查和生产构建通过；构建仍有既有 API 混合静态／动态导入提示。桌面 Node 离线测试 53／53 通过，包含正式句段替换、缩短、后续句段和空列表的映射测试。
- 使用 [浏览器回归脚本](../../../desktop/desk-preview/tests/conversation-review-regression.py) 和本地模拟接口／SSE／音频重跑 231 原始场景：临时句段被正式句段取代并恢复输入；后续正式句段仍需推进；第二句播放失败时第一句保持播放；第二句实际开始后才暂停第一句；离开页面时清理播放候选；过场图只在起始句段出现，缺失锚点单独展示；打开历史、定位和返回最新的舞台状态正常。7 组场景通过，结果保存在 `backend/test-results/fix-231-desktop/findings.json`。
- 浏览器脚本从仓库根目录执行：先在 `desktop/desk-preview/renderer` 执行 `npm run build`，再执行 `python desktop/desk-preview/tests/conversation-review-regression.py`；脚本使用本机 Chrome 无界面运行，模拟 `playing` 和失败，不代表真实音频设备验收。
