## 2. 开发顺序与文件边界

1. **FE-01 页面和演出状态。** 在 `desktop/desk-preview/renderer` 建立对话页面并替换占位入口。保留现有桌面导航、角色选择和视觉变量。舞台、对话列表、推进控件、输入框、历史面板和媒体控制按职责拆分。先使用模拟数据验收，与 CG 后端并行。
2. **FE-02 消息和语音接入。** 把窗口选择、快照、SSE、提交和按句合成集中到数据接入层。页面只读取统一的消息、句段、任务和播放状态。连接恢复及音频取消由接入层和播放器处理。等最新流式句段与 `emotion` 增量通过独立复核后完成正式联调。
3. **FE-03 过场图和历史。** 接入已复核的过场图任务和受管图片，完成手动触发、自动状态展示和历史打开。历史时间轴使用窗口级历史接口，按消息及句段 ID 定位。后端分页、检索和过场图可按契约分别联调。
4. **FE-04 桌面验收。** 用实际桌面运行方式验证键鼠、缩放、明暗、恢复、真实语音和生图。角色音色配置与试听进入设置工作包，桌面交付按现有项目流程留证。

## 3. 对话与舞台契约

- 以 `roleId + windowId` 隔离页面上下文。`messageId` 标识一轮，`segmentId` 标识台词或动作。输入、阅读位置和实时演出进度分别维护，历史定位只滚动右侧对话。
- 发送后隐藏输入框，等待首段自动显示。用显式「下一句」按钮推进到已就绪的下一段，键盘可聚焦并用 Enter 或空格激活。暂时没有下一段时提示等待，仍可回看右侧已展示内容。输入法组合期间的 Enter 交给输入法，输入框支持 Shift+Enter 换行。
- 以窗口快照的游标开始 SSE。生成中的 `message_segments` 带 `partial: true`，按 `segmentId` 追加或合并；终态句段列表作为完整结果。`message_delta` 用于恢复生成中文字，逐句展示使用后端句段。重复事件、切换角色及窗口后的迟到事件按归属处理。
- 已确认回复结束且最后一个正式句段已显示时恢复输入框，单句回复在首段自动显示时满足条件。失败或空回复没有可展示句段时显示终态并恢复输入框。有已保存残句则保留文字，显示到最后一段后恢复。音频、表情标注和图片是否已返回不参与输入框判断。
- 台词用气泡和小喇叭，动作及旁白用无气泡文字。立绘按当前演出句段切换，历史文本定位独立。输入框隐藏期间仍可使用历史和设置。正式交互省略显式停止按钮。
- 过场图按 `messageId` 与起止 `segmentId` 绑定，首尾均计入有效区间。纯背景图覆盖背景层，整幅图覆盖背景与立绘。离开区间恢复基础背景与当下句段立绘。仍在有效实时区间时可自动切入，已越过区间或在回看时只更新原句段入口。具体任务字段按 [223](223-conversation-performance-development-guide.md#3-过场图后端契约草案) 的复核结果接入。

## 4. 语音和历史接入

- 点击小喇叭始终按该句播放。开启自动播放后，仅推进到实时台词时自动播放，历史定位只移动文字。按后端 `speech` 路由合成，语音情绪可省略。缓存和预取以窗口、句段、当前音色配置与情绪为键，配置或窗口变化时释放过期结果。
- 正式端预取当前台词及后续可播放句段，异步合成失败时保留文字和点播重试入口。推进到动作段时继续播放已开始的语音，下一句音频实际播放时切换。已经离开句段的待播自动请求失效；离开窗口时清理播放和等待。
- 历史时间轴按当前窗口的已保存消息统计日期。关键词查询返回稳定的消息与句段锚点、命中文字及前后文。定位时补齐缺失分页，右栏滚到命中段并暂停跟随，点「回到最新」恢复跟随。旧过场图从句段入口打开。

## 5. 原型试用与正式验收

| 操作 | 可观察结果 |
| --- | --- |
| 打开 v5，发送「今天有点累」 | 第一段自动出现；「下一句」逐次展示动作和后续台词；末段显示时输入框同屏恢复。 |
| 加 `?scenario=single` 或 `?scenario=failure` 后发送 | 单句自动显示即恢复输入框。模拟空回复失败后显示提示并恢复输入框。 |
| 加 `?scenario=interrupted` 或 `?scenario=slow` 后发送 | 中断时保留已生成段落和「未说完」。慢回复时能观察输入框保持隐藏与「下一句还在准备」。 |
| 开启自动播放，或点击历史台词旁小喇叭 | 有本地中文音色时播放。点读入口始终可见，动作文字无语音。无可用中文音色时点读给出提示。 |
| 点轮次下的「生成过场图」，任选一种图层 | 出现生成状态并挂回原句段。点「查看」验证两种覆盖和收起。可在演出设置打开自动演示，或加 `?scene=1&scenario=slow` 验证晚到结果。 |
| 加 `?scenario=scene-failure` 后生成过场图 | 显示失败状态，已显示台词可继续读，舞台保留当前画面。 |
| 进入历史，搜索「杯子」并点片段 | 右栏定位动作或台词，历史定位独立于当前演出。可从结果所属句段打开旧过场图。 |

正式验收另覆盖窗口切换、SSE 重连和重放、当前轮异常恢复、媒体晚到、音色配置切换、完整窗口检索、缩小窗口、键盘操作及减少动态效果。原型验收用于确认交互与版式，正式验收记录真实数据和桌面运行证据。

v5 自验覆盖六个本地演出场景及 390 像素窄窗口交互。浏览器验证首末段、动作续播、晚到图片、图层和历史定位。语音测试使用受控朗读替身，另检查了桌面白昼和窄窗口夜间版式。
