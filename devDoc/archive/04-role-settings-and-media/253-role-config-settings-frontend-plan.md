# 角色配置与设置前端接入计划

> **样式约束更新**：本文涉及页面样式、组件与动效的实现约束，统一以现行 [前端设计规范](../../specs/frontend-design-system.md)（原 `307`）为准。

2026-11-11。原型基线为 `E:/tmp/testWorkSpace/switchboard/nowadays-config-demo/`，入口为 `index.html?page=role` 和 `index.html?page=settings`。两页与 [252 后端开发](252-role-config-settings-development-plan.md#5-后端验收与交接) 并行实施，已有接口可先接入，新增或待修接口按交接结果逐项联调。产品规则以 [161](../../161-digital-life-direction-decisions.md#dl-147-设置页编辑角色与当前陪伴角色分离) 为准。

## 1. 页面范围

| 页面 | 原型分区 | 接入方式 |
| --- | --- | --- |
| 角色配置 | 设定、外观、模型、扩展、自主额度、完成度 | 保留左页立绘、角色选择海报墙和右页分区。按编辑角色读取和保存，复用现有外观、声音和生图面板。 |
| 设置 | 模型、MCP、Skill、角色状态、本机 | 保留左页资源目录和右页详情。连接和模型测试在设置完成；角色页保留试听和样图。 |
| 双页导航 | Dock「更多」、从角色页查看或新增资源、停用后返回 | 复用应用导航与主题。跨页返回时恢复来源角色、分区和草稿。 |

正式页面使用 API 与应用内草稿，上传成功后按后端资源标识重新读取。原型的 `sessionStorage`、`window.name`、`demo=`、重置按钮及模拟结果用于对照交互。 [应用入口](../../../desktop/desk-preview/renderer/src/App.tsx) · [当前设置页](../../../desktop/desk-preview/renderer/src/pages/Settings.tsx) · [Dock](../../../desktop/desk-preview/renderer/src/components/shell/PageDock.tsx)

## 2. 并行实施与分批联调

### 立即开发

1. 拆出「角色配置」和「设置」两个入口。分别维护「正在编辑的角色」与「当前陪伴角色」，陪伴切换使用独立按钮。跨页返回恢复来源角色、分区和草稿。异步结果按发起角色归属，切换后仍以当前编辑角色为准。
2. 接入角色列表和详情、外观列表与现有导入、模型列表与主动测试、角色语音试听、ComfyUI 探测与已保存配置的文生图样图。模型界面提供手填 ID、密钥保留、替换和清除，操作失败保留草稿。记忆模型展示实际使用项和跟随对话状态。完成度使用真实数据，其必需项由产品确认。本机页接入实际可读写的偏好及后端状态。
3. 接入角色活动查询，按后端响应显示运行中、正在停止、已停止和请求失败。先完成角色状态、扩展占用和写入失败的界面状态，区分角色绑定开关与全局资源开关。

### 接口修复后联调

1. 第一包对应缺口复验通过后，联调停止与恢复，以及依赖后端确认停止的人设、角色配置保存和全局模型修改。人设保存沿用版本校验。遇到拦截时提供到「设置 · 角色状态」的入口，返回时保留草稿。 [255 复验](255-role-activity-independent-review.md#256-修复独立复验)
2. 绑定接口按已交付的版本契约接入，跨页新建服务成功后只预填来源角色的草稿，角色页显式保存时再提交绑定。第二包对应缺口复验通过后，联调 MCP／Skill 全局修改、停用和删除，按服务端响应展示占用原因及失败结果。 [258 复核](258-resource-management-independent-review.md)

### 新接口交付后接入

1. 按 252 第三包接入服饰改名、主页立绘补传或替换、服饰与差分删除，以及删除后的历史素材读取。复用现有导入预览、重名提示及分套结果。角色删除提供保留或清理记忆与对话两条路径，按后端契约处理当前角色和空列表。
2. 角色语音和生图按已有接口复用。全局 TTS、草稿样图和图生图以实际交付范围为准。

原型中按 TTS 模型保留多份语音的交互按 DL-149 调整。扩展占用提示按 DL-148 展示角色开启或原任务链使用权。

## 3. 桌面联调验收

| 场景 | 通过条件 |
| --- | --- |
| 编辑角色隔离 | 与甲对话时编辑乙，切页、导入或试听不切换陪伴角色。乙的晚到结果不覆盖后来选中的角色。 |
| 第一条对话 | 新建角色、在设置新增服务、返回并预填模型草稿、保存绑定、启动对话并收到第一条回复。其他草稿和扩展选择保留。 |
| 活动状态与操作拦截 | 后端确认已停止才允许对应写入。拦截原因清楚，可去角色状态页操作后返回原草稿。 |
| 删除与历史 | 角色删除显式选择保留或清理历史。选择保留时目录留在本机，角色从管理列表移除。仍在系统中的角色可按历史句段的素材 ID 读取原图。 |
| 试听与样图 | 失败原因来自后端。切角色或切页后旧结果不覆盖当前页面。试听与样图不出现在对话演出记录。 |
| 布局与交互 | 1440×840、1280×800、720×540 可完成关键操作。日夜主题切换时图片颜色稳定，减少动效模式可直接切换。键盘可进入导航和确认框，关闭弹层后焦点回到原入口。 |

252 后端三包已通过独立离线复验，可按上表执行双页整体验收。交付记录包括前端类型检查、桌面测试、生产构建和关键跨页流程实测。真实语音和生图联调按可用服务另留证据。 [252 后端交接](252-role-config-settings-development-plan.md#5-后端验收与交接)
