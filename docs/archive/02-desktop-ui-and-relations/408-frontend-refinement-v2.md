## 阶段四 · 启动封面与离窗确认

静态封面读取原有本机主题，使用画布令牌为原生窗口着色。首帧合成后开窗，握手成功才动态载入 React 业务入口。外部配置的服务与桌面自行启动的子进程都须通过健康检查。就绪结果在安装独立扩展协议代理和主帧签名后发布，重试共享同一在途操作，失败会清理托管子进程。应用保留冷启动选角。空地址、读取失败均允许下一次重新读取。

关窗和托盘退出共用一个在途请求。设置页使用现有草稿状态，确认纸笺沿用全局 Modal 的层级、焦点与昼夜外观。用户阅读期间，主帧每秒报告仍在响应；连续 4.5 秒无响应，主进程收回此请求的页内决定权，再打开原生对话框。只有当前窗口主帧的匹配决定可以消费一次请求。确认退出时销毁主窗，普通页面卸载仍由原草稿守卫处理。

## 默认并发转场与二次全页视觉补修
